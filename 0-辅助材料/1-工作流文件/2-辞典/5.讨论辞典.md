# 讨论写作辞典 v1.2

段落级叙事模式。**逻辑链层直接复用引言的「6 对象」封闭集**——讨论与引言共用同一套对象（按对象书写的章节统一范式）。一段讨论讲一个主导对象，逻辑链即该对象。对象层封顶 6 个、零新增、严格不细分。段内元素序列开放、逐段忠实记录，元素 ID 以**元素辞典 v3.8** 为准。

> **对象范式的适用边界（重要）**：6 对象是**「按对象书写」章节的统一范式**——引言、讨论，及将来的结果/结论等以"先想写哪个对象、再展开"方式书写的章节。**摘要不在此列**：摘要颗粒度本就对标元素层（十几句、句即一个动作 ≈ 引言的元素），且按**功能流程**书写（研究前/中/后），而非按描述对象书写，故摘要用其专属的"功能三相 + 动作链"组织，**不转 6 对象**。这不是"尚未统一"，而是摘要的叙事颗粒度与写作认知本就不属于对象范式适用范围。

> **对象命名（讨论专属后缀）**：6 对象与引言**语义同源但命名加「讨论」后缀**（疾病讨论 / 生物分子物质讨论 / 机制通路讨论 / 治疗方法讨论 / 研究方法讨论 / 本次研究讨论），引言侧为「…描述」。目的是在 Obsidian 双链中分章成节——`[[生物分子物质讨论]]` 与 `[[生物分子物质描述]]` 是不同节点，避免引言/讨论段落混链到同一节点。
> 
> **后缀与「全文对象链」的关系（澄清）**：后缀仅服务于**章节内双链分节**。**全文对象链拼接时按「对象基名」（去掉"描述/讨论"后缀的「生物分子物质」「机制通路」…）归并**，方能看出同一对象如何贯穿全文、在哪章登场交接。即：节点分章用后缀，全文链看贯穿用基名归并，两者不冲突。全文对象链仅由**对象类章节**（引言/讨论等）拼接；摘要作为全文功能浓缩，不混入对象链。

> **范式来源（实测确认）**：9 篇讨论实测（41905213/40139029/41240582/42157922/41890708/41415207/41523616/41699670/40049228）共 81 段，逐段立足点全部落进引言 6 对象，无一段主角逃逸，未冒出引言所无的新对象。故讨论不另立对象，整体沿用引言逻辑链。
> 
> **讨论 vs 引言的差别只在「频次」与「本次研究的内涵」，不在对象集合**：讨论里「生物分子物质讨论」「本次研究讨论」占比远高于引言；「本次研究讨论」在讨论中额外承载开篇总览、优缺点（strength/局限）、展望、创新点、应用意义等内容——但这些是**元素层的填充**，不改变逻辑链层的 6 对象。

## 判定总纲：判整段立足点，不判单句出现了什么

**核心判据（与引言一致，贯穿 6 对象）**：判这一段的**立足点**——整段主要在讲什么、落点在哪个对象。段里黏到的其他对象（援引的文献、佐证的通路、提到的治疗）一律降为**属性**，不改变段落归属。

- **判信息不判词**：不看段里出现了 consistent with / however / previous studies / limitation 等词，看整段在讲什么对象。
- **判主导对象（主）**：一段若涉及多个对象，判哪个是立足点（段落主体围绕谁展开），归该对象；其余作段内元素记录。
- **判终极落点（兜底）**：仅当主导对象不唯一（前半铺陈对象A、后半实质转向对象B）时启用，以该段最终落在哪个对象为准；但末句的钩子/承转句（"机制尚不清""值得未来研究"）**不算落点转移**，仍按整段主体归类。
- **文献援引是手段，不是对象**：讨论几乎每段都援引既往文献。援引谁、印证还是矛盾、是否填补空白——一律是**服务于描述某对象的素材与关系方向**，由元素/句子承载，**不立「文献对照」对象**。立足点永远是被讨论的那个事物（分子/机制/治疗/疾病/本研究），文献是它的属性。
- **关系方向是属性**：与文献的印证/矛盾、与疾病的致病/保护/预后，方向由元素承载，不另立对象。

## 逻辑链（6 对象，复用引言，封闭集，零新增）

### 疾病讨论

整段立足疾病本身——病的负担、亚组/分期特征、发病机制（本病层面）、暴露-病关联背景等。讨论中低频，多见于交代某发现所处的疾病背景或亚组分析。

- **立足点**：这段在讲"这个病/这种暴露-病关联本身是怎么回事"。
- **讨论侧示例**：某研究 CKD 亚组段（立足 CKD 患者心血管风险这一疾病背景）、ED 暴露与前列腺癌关联的背景段。
- **与生物分子讨论区分**：立足病/暴露本身 → 疾病讨论；立足某分子在病里做什么 → 生物分子物质讨论。
- **与本次研究讨论区分（亚组发现的两可）**：立足"某疾病亚组本身的背景/特征" → 疾病讨论；立足"本研究在该亚组中的新发现" → 本次研究讨论。按整段主体判（见记观察）。

### 生物分子物质讨论

整段立足一个**可命名的单个实体**——基因/蛋白/受体/代谢物/化合物/暴露物。讲它是什么、有何功能、在本病中扮演什么角色、本研究对它的发现。**讨论中最高频对象**——讨论主体常是逐个剖析核心基因/蛋白。

- **立足点**：这段在讲"某一个分子/物质实体是什么、做什么、本研究发现它怎样"。
- **讨论侧示例**：逐基因功能剖析段（一段一个核心基因，述其功能+文献佐证+本研究观察）、单个受体/代谢物的角色论证段。
- **与机制通路讨论区分**：主角是点状单个实体 → 本对象；主角是一套系统/过程 → 机制通路讨论。实体援引的通路、援引的文献均为属性。
- **与本次研究讨论区分**：立足"这个分子本身是什么/做什么" → 本对象；立足"本研究发现/选取了它"且整段在讲本研究 → 本次研究讨论（见边界焊点1）。

### 机制通路讨论

整段立足一**套可命名的机制系统**——信号通路（NF-κB / cGAS-STING / IL-6-STAT3）、程序性死亡、氧化应激/炎症反应过程、修饰、结构识别机制（如配体口袋如何识别底物）等。讲这套系统如何运转、如何被本研究的发现牵动。组成它的分子是部件（属性）。

- **立足点**：这段在讲"某一套机制/过程系统如何运作、本研究的发现如何嵌入其中"。
- **讨论侧示例**：氧化应激如何驱动肿瘤的机制段、cGAS-STING 放大无菌炎症的机制段、受体识别配体的结构机制段。
- **与生物分子物质讨论区分**：系统过程 vs 点状实体。
- **与疾病讨论区分**：机制作为独立系统（可跨病）→ 本对象；机制依附于本病发生且整段立足病 → 疾病讨论。

### 治疗方法讨论

整段立足**用某手段对付本病**——候选药/天然产物/已上市药/成药性评估/疗法对比的现状、效果、局限，或论证某治疗候选值得用。提到的起效机制、援引的证据是说明（属性）。

- **立足点**：这段在讲"用什么手段治这个病、治得怎么样、值不值得用"。注意：应用意义、临床转化前景若整段围绕"某治疗手段值不值得用"展开，主角仍是治疗方法，"意义"是姿态。
- **讨论侧示例**：抑制某靶点作为治疗策略的论证段、候选药对接结果+既往用药证据段、与现有标准疗法（如抗 VEGF）对比段、成药性/递送策略段。
- **与生物分子物质讨论区分**：讲"用它怎么治"（施用）→ 本对象；讲"它的分子本质"→ 生物分子物质讨论。
- **与本次研究讨论区分**：立足治疗手段本身的评价 → 本对象；立足"本研究证明/筛选了此疗法"且整段在讲本研究 → 本次研究讨论（看终极落点）。

### 研究方法讨论

整段立足**某研究方法/技术/工具本身的工具属性**——MR、多组学、机器学习、网络毒理、分子对接、测序等的原理、适用范围、方法学固有缺陷。

**关键事实（讨论专属）**：讨论里出现的方法**必然是本研究用过的**，故引言那条"产权属领域 vs 属本研究"的判据在讨论中失效。本对象在讨论中**近乎空集**，仅作兜底保留以维持「按对象书写」章节的对象集合一致（引言侧实打实使用此对象）。

- **立足点**：这段在讲"某方法作为工具本身怎么样"，且**完全剥离了本研究的具体发现/结论**。
- **触发条件（极严）**：整段是纯方法论反思，不挂任何本研究结果。例如独立成段讨论"MR 易受水平多效性与弱工具变量偏倚干扰"而通篇不连到本研究任一发现。
- **否决式硬规则**：**只要段落用该方法去支撑、得出或修饰某条本研究的发现/结论（"用此法我们发现X""此法使我们的Y结论更可靠""此法在本研究中的局限影响了Z"），即禁止归入本对象，一律归本次研究讨论。** 方法在该段是属性，不是主角。

### 本次研究讨论

整段立足**本研究本身**——开篇结果总览、核心发现重述、研究的创新点、**优缺点（strength 与局限）**、未来展望、研究的整体意义/价值定位、方法学价值。**讨论中高频且内涵最重**：讨论的开篇总览段、独立的局限段、strength 段、展望段、收束段几乎全归此。

- **立足点**：这段在讲"本研究做了什么、发现了什么、强在哪、有何不足、下一步如何、整体价值如何"。
- **天然涵盖优缺点**：strength / 局限 / 创新 / 展望 / 意义都是对"本研究"这一个对象的不同侧写，立足点都是"我这项研究怎么样"。它们彼此的区别（自夸 vs 自承短板 vs 指下一步）是**姿态差异**，以段内元素区分，**不另立"局限对象""优势对象"**。这正是六对象封顶仍能稳稳兜住讨论优缺点的原因——若按姿态拆对象，局限/展望会无家可归。
- **讨论侧示例**：开篇"本研究整合X发现Y"总览段（点名的分子/机制/治疗全是属性）、"several limitations"局限段、"this work has several strengths"段、strength+局限混写段、"future studies"展望段、"in summary"收束段、"our integrative framework"方法学价值段。
- **与各事物对象区分（讨论第一焊点，见下）**：立足"我这项研究" → 本对象；立足"某分子/机制/治疗本身是什么" → 各归各。
- **与研究方法讨论区分**：方法用来支撑本研究任一发现/结论 → 本对象（方法是属性）；整段纯评介方法工具属性、不挂任何本研究结果 → 研究方法讨论。

## 关键边界焊点（讨论专属，最易混区）

1. **本次研究讨论 vs 各事物对象（讨论第一焊点）**：讨论开篇总览段会一口气点名分子+机制+治疗，但整段立足"本研究整合X、发现Y"，主角是本研究，点到的事物全是属性 → 本次研究讨论。反之，逐个剖析某分子/某机制本身、本研究观察只作其中一句佐证的段 → 各事物对象。判据：问"这段在讲我这项研究，还是在讲这个东西本身？"
    
2. **研究方法讨论 vs 本次研究讨论（讨论第二焊点）**：因讨论里方法必属本研究，分界改用"工具属性 vs 本研究产出"。整段把方法当工具评介其原理/适用/方法学缺陷、且不连任何本研究发现 → 研究方法讨论（罕见）。**只要方法被用来支撑/得出/修饰本研究的任一发现或结论，否决归入研究方法讨论，一律本次研究讨论**（方法降属性）。
    
3. **生物分子物质讨论 vs 机制通路讨论**：与引言同款。点状单个实体（逐基因剖析）→ 分子；一套系统过程（氧化应激/炎症/通路/结构识别如何运转）→ 机制通路。黏连的另一方降属性。
    
4. **治疗方法讨论 vs 生物分子物质讨论**：讲"用它怎么治本病/作为靶点抑制它"（施用）→ 治疗方法；讲"它是什么分子、有何功能"（本质）→ 生物分子。同一个分子可在相邻两段分属两个对象（前段讲它是什么=分子，后段讲抑制它来治病=治疗）。
    
5. **治疗方法讨论 vs 本次研究讨论**：立足"某疗法/候选药值不值得用、与标准疗法比如何"（疗法本身的评价）→ 治疗方法；立足"本研究筛选/验证了此疗法"且整段在讲本研究（产权属本研究的动作）→ 本次研究。看终极落点。
    
6. **文献援引一律不立对象**：印证/矛盾/补空白是关系方向（属性），援引的同行工作是素材；整段主角仍是被援引文献所服务的那个事物。绝不因"这段引了很多文献"就另设对象。

## 记观察（不强行焊，待实测积累）

- **亚组发现段（疾病讨论 vs 本次研究讨论）**：如某研究在 CKD 亚组中的发现段（文9段3）。立足"该疾病亚组本身的背景/特征" → 疾病讨论；立足"本研究在该亚组中得到的新发现" → 本次研究讨论。两可，按整段主体判，记录积累。
- **应用意义 / 临床转化段的归属**：多数立足某治疗手段（→治疗方法讨论）或立足本研究整体价值（→本次研究讨论）。极少数纯泛谈"本领域意义"两可，遇具体案例按主角判，记录积累。
- **逐基因段中"基因功能"与"基因所在通路"的主从**：逐基因剖析段以基因为点状主角（→生物分子物质讨论），即便段中展开了该基因牵动的通路；仅当整段升格为讲通路系统本身如何运转才转机制通路讨论。低频两可，记录。
- **方法学价值段**：若整段立足"本研究这套整合框架是方法学贡献"→本次研究讨论（产权属本研究）；不归研究方法讨论（后者是客观评介领域内方法工具本身）。
- **研究方法讨论是否长期保留**：本对象在讨论中近乎空集，暂留以维持对象集合一致。若跨更多篇实测始终为空，再议是否在讨论侧标注为"休眠对象"。

## 归类流程

1. 识别讨论段落（按标题归一化定位 Discussion 区）。
2. 对每段：判**整段立足点（主导对象优先，终极落点兜底）**落在 6 对象的哪一个 → 标该对象逻辑链。先问"主角是本研究自己，还是某个被讨论的事物？"再在事物内部分分子/机制/治疗/疾病；方法默认降属性归本次研究，除非纯方法论反思。
3. 段内逐句标元素（描述动作，承载"怎么写这个对象"，含讨论特有的文献援引/印证/优缺点/展望/意义等姿态，由讨论元素清单提供）。
4. 文献援引、印证/矛盾方向、黏连的其他对象 → 作段内元素/属性记录，不改段落对象归属。

> 6 对象封顶、零新增，与引言（及将来结果/结论）语义统一（仅命名后缀分章）；摘要不在对象范式内（功能三相+动作链）。全文对象链由对象类章节段落对象按基名归并派生拼接（派生视图，非新层、无新增判定）。复杂度放元素端。
