# 摘要 / 引言 工作流说明书

> 适用于「论著阅读流水线 / 综述阅读流水线」Tauri 应用中的**摘要**与**引言**两条工作流。 引言工作流后半段包含**知识点提取**子流水线与**同步定义**。本文按"真实脚本行为"编写。

---

## 一、总览

两条工作流都把 Obsidian 里的原始文献笔记，逐句拆成"叙事功能元素 + 逻辑链"，落到三类笔记里供写作复用：

|工作流|输入|产出笔记|子流水线|
|---|---|---|---|
|摘要|文献笔记的 Abstract 段|摘要逻辑链笔记、共用元素笔记、Mermaid 逻辑图|Mermaid 可视化|
|引言|文献笔记的 Introduction 段|引言逻辑链笔记、共用元素笔记、知识点笔记|知识点提取、同步定义|

**元素笔记是两条流水线共用的**（同一个 `element_notes_dir`）；逻辑链笔记、知识点笔记各自独立。

---

## 二、公共基础

### 2.1 三层架构

```
React 前端 (App.tsx)         定义步骤卡片 / 章节 tab / 状态与日志
   ↓ invoke("run_step", id)
Rust 后端 (lib.rs)           薄壳：配置持久化 + 进程桥接，run_step 通用透传（无 step 白名单）
   ↓ call_runner([id, config])
runner.py (DISPATCH 表)      step id → run_xxx 函数
   ↓
领域脚本 (*.py)              真正的业务逻辑，stdout 末行返回 StepResult JSON
```

新增/删除一个步骤 = 改三处：`App.tsx` 的步骤数组 + `runner.py` 的 `DISPATCH` 与函数 + 对应 `.py`；后端不动。

### 2.2 配置（config.json）

路径键由各 markdown 文件 YAML 里的 `配置键:` 列表在初始化时自动连接（须用列表格式：`配置键:\n - key`，不能写成行内 `配置键: key`）。常用键：

|键|含义|
|---|---|
|`待分析文献文件夹`|原始文献笔记目录（含 Abstract / Introduction 原文）|
|`element_dictionary_file`|元素辞典 v3.4（67 元素，A–H 层，**跨章节共用**）|
|`element_notes_dir`|共用元素笔记目录|
|`abstract_dictionary_file` / `abstract_notes_dir` / `abstract_ai_result`|摘要写作辞典 v2.7 / 摘要逻辑链笔记 / 摘要 AI 结果|
|`introduction_dictionary_file` / `introduction_notes_dir` / `introduction_ai_result`|引言写作辞典 v1.3 / 引言逻辑链笔记 / 引言 AI 结果|
|`knowledge_dictionary_file` / `knowledge_notes_dir` / `knowledge_ai_result`|知识点辞典 / 知识点笔记 / 知识点 AI 结果|
|`*_prompt_template`|对应的 AI 分析指令文件|
|`mermaid_prompt_template` / `mermaid_dictionary_file`|Mermaid 指令 / Mermaid 辞典|

### 2.3 辞典体系

|辞典|管什么|结构|
|---|---|---|
|元素辞典 v3.4|句子级标签（67 个，A 疾病描述 … H 结论）|`### 层` 下 `- 名称：定义`|
|摘要写作辞典 v2.7|21 条摘要逻辑链|`### 层` + `- 名称：定义`|
|引言写作辞典 v1.3|16 条引言逻辑链|**`**名称** 定义`**（粗体名行 + 子项 `- 典型元素序列/与X区分`）|
|知识点辞典|限定词级具象知识|`### 维度` 下 `- 知识点名`|

> 元素辞典只管句子标签，**不得**用于命名逻辑链；逻辑链名也不得出现在句子标注里。

### 2.4 笔记结构约定（重要）

所有**元素笔记**和**逻辑链笔记**统一骨架，文件名本身即标题，**不再写 `# 文件名` 一级标题，`# 整理` 与 `# 未整理` 之间无 `---` 分隔线**：

```
---
<YAML 属性>
---

# 整理            ← 人工归档区，脚本永不触碰
# 未整理          ← distribute 的分发落点（楼层保护：分发只发生在此标题之后）
## 摘要 / ## 引言 / ## 实例 / ## 论著 / ## 综述
...
```

- **共用元素笔记**（`element_notes_dir`）：同一个文件既收摘要句（`## 摘要`）也收引言句（`## 引言`）。谁先建笔记就立骨架，另一条流水线发现已存在 → 只往 YAML `章节` 补一项 + 把自己的 `## 摘要`/`## 引言` 追加到 `# 未整理` 末尾，两段并存。
- **知识点笔记**结构不同（非共用）：`# 知识点名` + `## 元素 → ### 引言 → #### PMID → 原文`。

### 2.5 「已参考论文」机制

辞典末尾 `## 已参考论文` 区按章节标签记录已处理 PMID，assemble 时据此跳过：

- **新批次置顶**：每次回写把新 PMID 放最上面，旧记录保持原文件顺序（稳定的"新→旧"堆叠）。
- **读取健壮**：兼容多行、逗号、bullet；多行 PMID 会全部读到（旧版只读首行的 bug 已修）。
- **谁写谁读**见各工作流；要点：**引言链的已参考回写推迟到知识点分发**（见 §4.5）。

## 三、摘要工作流

步骤（前端卡片）：`未参考筛选` → `摘要拼接` → `笔记创建+分发` → `Mermaid拼接` → `Mermaid回写`。

### 3.1 未参考筛选（前置动作）

扫描 `待分析文献文件夹`，对照 `摘要:` 已参考列表，列出还没做摘要的文献；可切到"批量清空"模式。

### 3.2 摘要拼接 `assemble`

- 读已参考(摘要) → 扫描待处理文献的 Abstract → 分句 → 拼 prompt（元素辞典 v3.4 + 摘要写作辞典 v2.7 + 摘要分析指令）→ 复制剪贴板。
- 粘到 AI，得到 `摘要 AI 结果`：每篇含 `结构类型`（一段式/分段式）、逐段 `逻辑链名称`（只写名称）、`句子标注`（**每句一个 `[元素]`**）、`新发现`。

### 3.3 笔记创建+分发 `create_and_distribute`

`abstract_create_notes` + `abstract_distribute` 合并解析一次：

- **逻辑链笔记**（`abstract_notes_dir`）：YAML `章节:摘要 / 定义 / 逻辑链形式(一段式|分段式) / 分段内容(背景..结论)`；正文骨架 `## 实例`。实例为**无序列表**：`- (PMID: x): [元素] → [元素] → …`。
- **元素笔记**（共用）：YAML `章节:摘要 / 笔记类型:元素`；句子落到 `## 摘要` 下，`### PMID: x` + `- 原文`。
- **查重按子区**：摘要句的 `### PMID` 只在本笔记 `## 摘要` 段内查重，不与 `## 引言` 撞车；楼层保护确保只写 `# 未整理`。
- 更新摘要辞典/元素辞典；**写回 `摘要:` 已参考**（摘要链自包含，回写就在这一步）。

### 3.4 Mermaid 拼接 / 回写 `mermaid_assemble` / `mermaid_write`

- 拼接：读句子标注 + 锁死配色规范 → 生成"摘要逻辑图" prompt（AI 自由分段）→ 剪贴板。
- 回写：解析 Mermaid 结果，按 PMID 拆分，插入原文献笔记的 Abstract 区域。
- 图布局约定：`flowchart TD` 宏方向、subgraph 内 `direction LR`、锁死 `%%{init}%%`（nodeSpacing 28 / rankSpacing 34 / fontSize 17px）；节点关键词加粗用 `<b>kw</b>`（非 `**`）。

## 四、引言工作流

步骤：`未参考筛选` → `引言拼接` → `笔记创建+分发` → `知识点拼接` → `知识点笔记+分发` → `同步定义`。

### 4.1 引言拼接 `intro_assemble`（含"手选模式" `intro_assemble_manual`）

- 从**元素辞典**读 `引言:` 已参考 → 扫描待处理文献的 Introduction → **按段落切分** → 拼 prompt（元素辞典 v3.4 + 引言写作辞典 v1.3 + 引言分析指令）→ 剪贴板。
- AI 结果：每篇 `引言类型`、逐段 `### 第N段 逻辑链`（只写名称）+ `句子标注`（**每句一个 `[元素]`**）、`新发现(新逻辑链/新元素)`。

### 4.2 笔记创建+分发 `intro_create_distribute`

`introduction_create_notes` + `introduction_distribute`：

- **逻辑链笔记**（`introduction_notes_dir`）：YAML `定义 / 文章性质 / 段落分布`；正文按文章性质分 `## 论著` / `## 综述`；实例为**无序列表**：`- (PMID: x, 第N段): [元素] → …`。
- **元素笔记**（共用）：句子落到 `## 引言` 下，`### PMID: x` + `- (第N段) 原文`。
- 序列由脚本据句子标注派生（模型不写序列）；**查重按 `## 引言` 子区**；楼层保护。
- 更新引言辞典（新逻辑链以 `**名称** （待补充说明）` 追加）、元素辞典。
- **不再写已参考**（已移到知识点分发，见 §4.5）。

### 4.3 知识点拼接 `knowledge_assemble`

- 源是 `introduction_ai_result`（已分析好的引言结果）；按 `知识点辞典` 的 `知识点:` 已参考过滤 → 拼 prompt（元素辞典 + 知识点辞典 + 知识点提取指令）→ 剪贴板。
- 知识点 = 限定词 + 相关知识（如"酒精性肝病相关知识""孟德尔随机化相关知识"）；附维度（研究对象/研究方法/治疗手段）+ 逻辑链名。

### 4.4 知识点笔记+分发 `knowledge_create_distribute`

`knowledge_create_notes` + `knowledge_distribute`：

- **知识点笔记**（`knowledge_notes_dir`）：YAML `章节:引言 / 逻辑链 / 维度 / 包括元素`；正文 `## 元素 → ### 引言 → #### PMID: x → 原文`（套话元素 `SKIP_ELEMENTS` 不入正文）。
- 更新知识点辞典（新知识点按维度追加 + 写 `知识点:` 已参考）。
- **回写双链**：把引言 AI 结果表格里的知识点名替换为 `[[双链]]`。
- **回写原文献**：删除原文献笔记的 `## Introduction` 原文，替换为知识点表格。

### 4.5 已参考回写的位置（关键设计）

- 引言 distribute **不写**已参考——避免引言分析一做完就把论文标成"已处理"，挡住后面的知识点提取。
- 知识点 distribute 是引言链的最后一步，这里一次性写：
    - `知识点:` → 知识点辞典（知识点 assemble 用它去重）；
    - `引言:` → 元素辞典 + 引言辞典（引言 assemble 用它去重），用**整个引言批次的 PMID**标记。
- 含义：只有跑完知识点提取，这批论文才算"引言链处理完"，引言 assemble 之后才跳过它们。
- ⚠ 副作用：同一批只跑了引言、没跑知识点就又跑引言 assemble，会被重新提取——按"引言→知识点"顺序走即可。

### 4.6 同步定义 `sync_definitions`（保留）

顺序执行 `sync_element_descriptions`（更新元素功能描述）+ `sync_chain_definitions`（更新逻辑链定义），把辞典里的定义/功能描述**同步进已建好的笔记**（create_notes 对已存在笔记跳过，靠它补；也可能反向同步）。属维护工具，按需运行。

## 五、关键规则速查

1. **单标签**：每句只标一个 `[元素]`，严禁 `[元素A][元素B]`。理由：Markdown 会把 `[A][B]` 当引用链接、只显示第一个；双标签多是模型在两标签间犹豫而非辞典缺项。看似身兼两职时按主导功能取唯一标签（目的 ＞ 方法 ＞ 证据）；确实无对应才新建元素登记。
2. **逻辑链只写名称**：序列由脚本据句子标注逐句拼接，节点数恒等于句子数；逻辑链名不会混入序列。
3. **共用元素笔记**：跨章节查重按子区（`## 摘要` / `## 引言` 各自查 `### PMID`）；`# 整理` 人工区受楼层保护永不被写。
4. **实例无序列表**：逻辑链笔记实例统一 `- (PMID …): …`。
5. **已参考置顶**：新批次在最上、旧的保持原顺序。

## 六、典型一次跑批顺序

**摘要**：未参考筛选 → 摘要拼接 →〔AI〕→ 笔记创建+分发 → Mermaid拼接 →〔AI〕→ Mermaid回写。

**引言**：未参考筛选 → 引言拼接 →〔AI〕→ 笔记创建+分发 → 知识点拼接 →〔AI〕→ 知识点笔记+分发 →（按需）同步定义。

> 同一批论文，先把引言链完整跑到"知识点笔记+分发"，再开下一批；不要在做知识点之前重复跑引言 assemble。

## 七、故障排查（已知问题与处置）

|现象|原因|处置|
|---|---|---|
|元素笔记 `# 整理`/`# 未整理` 间有 `---`|改造前建的老笔记|跑 `normalize_notes.py`（先预览，再 `--apply`）|
|引言句子没进共用元素笔记|跨章节 `### PMID` 查重撞车（摘要先写过同一 PMID）|已修：查重改为按子区；用新版 distribute|
|逻辑链里 `[A][B]` 只显示一个|多标签被当引用链接|已禁多标签；用新指令**重跑** AI（旧结果里的多标签仍只显示首个）|
|知识点重复提取已做过的论文|`extract_referenced_pmids` 多行只读首行|已修：`knowledge_assemble` 改健壮逐行扫描|
|tab 下第二条彩线很怪|进度条写死彩虹渐变，与章节色不一致|已改：进度条用当前章节色（与 tab 下划线统一）|
|知识点提取被引言阶段挡住|引言 distribute 过早写已参考|已改：已参考回写移到知识点分发|
