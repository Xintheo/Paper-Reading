# 结果工作流说明书

> 论文 Results 章节的笔记化流水线。两阶段（宏观套路+图例 → 微观切片+元素），加结果汇总两个去向。 本文档面向作者本人，记录每步的按钮、stepId、配置键、文件夹位置、数据流。

---

## 二、第一阶段：宏观套路 + 图例

目的：从 Results 抽「研究套路」和「图例（逐子图方法/图形）」，建套路笔记和图形笔记。

### 步骤 1｜套路拼接　`results_pattern_assemble`（备选手选：`results_pattern_assemble_manual`）

- 读已参考 PMID（结果辞典）→ 扫各论文 Results → 拼「套路辞典 + 本文方法名清单 + 套路分析指令」→ 剪贴板。
- 贴给 AI，AI 按指令输出到 `results_ai_output_file`。
- AI 输出顺序（指令已固定）：**具体图例 → 图例概括 → 套路总结**（具体图例放最前便于人工审核）。

### 步骤 2｜更新图例概括　`results_legend_rollup`

- **人工审核「具体图例」表后**跑此步。脚本读具体图例表 → 按图号（Fig.N，三重保险：纯数字列→正文Fig.N→字母循环兜底）分组 → 把每张图所有子图的「研究方法」「常用图形」去重合并 → 追加/覆盖回「图例概括」表的对应两列。
- 原地改写 `results_ai_output_file`。只做「具体图例 → 图例概括」单向汇总。

### 步骤 3｜套路+图例创建　`results_pattern_create`

- 解析 `results_ai_output_file` 的「套路总结」+「图例」两块。
- **套路笔记**（→ `results_pattern_notes_dir`）：段落套路 + 文章套路。结构 `# 整理 / # 未整理`（逻辑链行进未整理），frontmatter 含套路类型/定义/逻辑链；新建套路按「套路分类」分发进套路辞典对应小节。
- **图形笔记**（→ `results_legend_notes_dir`）：按常用图形名建（森林图.md 等）。结构 `# 整理 / # 未整理 / ## Legend / ## 原文`。Legend 段收该图形所有子图的「具体文本」原文；frontmatter `常用方法: - "[[方法名]]"`。
- 解析按**列名**定位（不按列位置），增删列不会错位。

---

## 三、第二阶段：微观切片 + 元素

目的：Results 逐句切片、打三标签（方法/展示元素/图形），建方法展示笔记和元素笔记。

### 步骤 4｜结果拼接　`results_assemble`（备选：`results_assemble_manual`）

- 扫 Results → 拼「展示元素辞典（结果辞典）+ 本文方法名清单 + 第一阶段具体图例对照表 + 结果分析指令」→ 剪贴板。
- **对照表整段透传**第一阶段「具体图例」表（自带表头），不再自补表头（避免列错位）。
- 贴给 AI，AI 按句切片输出到 `results_slice_output`，每行 `(方法名)[展示元素][图形名]: 原句`。

### 步骤 5｜结果笔记创建　`results_create_notes`

- 直接读 `results_slice_output`（PMID 取自 `## 文献N (PMID)` 标题，不需预先回填）。
- **方法展示笔记**（→ `results_result_notes_dir`）：每方法一笔记 `XXX的结果展示.md`。结构 `# 整理 / # 未整理`（下含 `## 展示逻辑链` + `## 原文`）；frontmatter `研究方法: - "[[方法名]]"`（供 Obsidian Base 显示，已去掉正文 ## 相关方法 段）。逻辑链由脚本从切片重建，不采信 AI 写的。
- **展示元素笔记**（→ `results_display_notes_dir`）：9 个（目的/操作/举数/比较/趋势/归纳/转折/验证/收束）。结构 YAML（功能描述+孤儿句位置）+ `# 整理 / # 未整理 / ## 原文`。
- **图形笔记**：往第一阶段已建图形笔记的 `## 原文` 段追加切片句子（精确匹配该段，绝不重复建 ## 原文）。
- `(段落)` 孤儿句只进元素笔记 + 回写段落套路笔记逻辑链。

---

## 四、结果汇总（两个去向）

第二阶段后，AI 把每篇结果汇成「研究目的 | 涉及方法 | 关键发现」表。

### 步骤 6｜具体结果拼接　`results_summary_assemble`

- 读 `results_slice_output` + `results_summary_prompt` → 剪贴板 → AI 输出汇总表到 `results_summary_output`。

### 步骤 7｜具体结果回贴　`results_summary_inject`

一个按钮做两件事：

1. **回贴各篇论文笔记**：按 PMID 把汇总表替换进每篇原论文笔记的 Results 段；回贴成功的 PMID 锁进结果辞典「已参考·结果」（下次拼接跳过，防重复闸门）。
2. **汇入集中检索库**（挂在回贴之后）：把同一份汇总表按 PMID 增量汇入 `results_summary_knowledge_note`（结果表格总结.md）。
    - 形态：`# 整理 / # 未整理`，未整理区按 `## {PMID}` 分组，每条 `- **研究目的**：关键发现`（跳过涉及方法）。
    - 列表形态（非表格），免疫 `|` 崩格式。整篇去重：该 PMID 分组已存在则整篇跳过。
    - 笔记不存在则新建，frontmatter 仅 `知识点层级: 表格` / `章节: 结果`。
    - 用途：后期检索拼表喂 AI，分析可引用的相关论文。

---

## 五、图像定义（辅助，可随时跑）

### 图像定义拼接　`results_image_def_assemble`

- 扫图像辞典中**空定义**的图形 + 同名图形笔记的 Legend/原文素材 + 图像定义指令 → 剪贴板。数据源是已落地的图形笔记，不依赖中转站。

### 图像定义更新　`results_image_def_update`

- 解析 AI 两列表 → 回填图像辞典空定义行（**不覆盖**已有定义）。

---

## 六、套路同步（辅助）　`sync_routine_from_dict`

- 中转站文章套路 → 回贴套路辞典「文章套路」表（去重）+ 按 PMID 回贴原文笔记 YAML（文章套路属性）。`[新建]` 残留自动跳过。

---

## 七、典型操作顺序

```
第一阶段：套路拼接① → (贴AI) → 人工审核具体图例表 → 更新图例概括② → 套路+图例创建③
第二阶段：结果拼接④ → (贴AI) → 结果笔记创建⑤
汇总：    具体结果拼接⑥ → (贴AI) → 具体结果回贴⑦（自动含回贴单篇 + 汇入检索库）
辅助：    图像定义拼接/更新、套路同步（按需）
```

> 笔记骨架统一：所有结果笔记（套路/图形/方法展示/元素/汇总）均为 `# 整理`（留空人工归整）+ `# 未整理`（脚本产出）两区结构。
