# 摘要工作流说明书

> 论文 Abstract 章节的笔记化流水线：分句 → 打逻辑链/元素标签 → 建笔记 → 可选 Mermaid 可视化。 摘要与引言**共用同一套元素辞典/元素笔记**（element_*），逻辑链各自独立。 本文档面向作者本人，记录每步的按钮、stepId、配置键、文件夹位置、数据流。

---

## 一、文件夹与配置键总览

目录配置在 runner.py 的 `_REL_FOLDER_DEFAULTS`，相对 Vault 根，运行时自动拼绝对路径。

### 笔记产出目录

|配置键|默认路径|存什么|
|---|---|---|
|`abstract_notes_dir`|`2-文献摘抄/1-摘要笔记`|摘要逻辑链笔记|
|`element_notes_dir`|`2-文献摘抄/0-元素笔记`|元素笔记（摘要/引言共用）|

### 指令 / 辞典 / 中转站文件（在 App 文件设置里指定）

|配置键|所在 App 文件夹|用途|
|---|---|---|
|`abstract_prompt_template`|1-AI指令|摘要分析指令|
|`abstract_dictionary_file`|2-辞典|摘要写作辞典（逻辑链定义+标题变体+已参考PMID）|
|`element_dictionary_file`|2-辞典|元素辞典（摘要/引言共用，含已参考PMID）|
|`abstract_ai_result`|3-中转站|摘要 AI 结果（逻辑链+句子标注+新发现）|
|`mermaid_prompt_template`|1-AI指令|Mermaid 指令（可选，缺则用内置默认）|
|`mermaid_dictionary_file`|2-辞典|Mermaid 配色辞典（可选，缺则用内置默认）|

## 二、主流程

### 步骤 1｜摘要拼接　`assemble`

- 读已参考 PMID（**元素辞典**）→ 扫各论文 Abstract（按摘要辞典里的标题变体识别，做分句与 section 归一化）→ 拼「摘要分析指令 + 元素辞典 + 摘要写作辞典 + 各论文 Abstract」→ 剪贴板。
- 跳过已参考论文；无新增则提示。
- 贴给 AI，AI 输出到 `abstract_ai_result`。AI 输出结构由 `parse_ai_result.py` 解析：支持一段式 / 命名分段式 / 编号分段式，含「逻辑链 + 句子标注」和「新发现（新逻辑链/新元素/标题变体）」。

### 步骤 2｜笔记创建+分发　`create_and_distribute`（= `create_notes` + `distribute` 合并）

**创建** (`create_notes`)：

- 解析 `abstract_ai_result` → 收集所有逻辑链 + 元素。
- 创建逻辑链笔记（→ `abstract_notes_dir`，含逻辑链定义）。
- 创建元素笔记（→ `element_notes_dir`）。

**分发** (`distribute`)：

- 把实例/例句分发进逻辑链笔记和元素笔记。
- 更新摘要写作辞典 + 元素辞典（登记新逻辑链/新元素/标题变体）。
- 更新「已参考」到**摘要辞典和元素辞典两处**（防重复闸门）。

> 创建失败则中止、不分发。

---

## 三、Mermaid 可视化（可选）

把摘要分析结果转成 Mermaid 流程图，回写进原论文笔记的 Abstract 区。

### 步骤 3｜Mermaid 拼接　`mermaid_assemble`

- 读 `abstract_ai_result` 的句子标注 → 按辞典配色规范（或内置默认）→ 拼 Mermaid 指令 → 剪贴板。
- AI 自由分段生成图、配色锁死，输出回 `abstract_ai_result`。

### 步骤 4｜Mermaid 回写　`mermaid_write`

- 解析 AI 的 Mermaid 内容块 → 按 PMID 定位原论文笔记（在 `待分析文献文件夹`）→ 插入 Abstract 区域。
- 回写后**清空中转站正文**（保留 frontmatter）。

---

## 四、典型操作顺序

```
主流程：  摘要拼接① → (贴AI) → 笔记创建+分发②
可视化：  Mermaid拼接③ → (贴AI) → Mermaid回写④（按需）
```

> 设计要点：
> 
> - 已参考 PMID 同时写进摘要辞典和元素辞典，是防止同篇重复处理的闸门。
> - 元素体系（element_*）与引言工作流共用——同一个元素笔记会同时收摘要和引言的例句。
> - Mermaid 是独立可选支线，不影响主笔记产出。
