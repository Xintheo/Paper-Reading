# 方法写作工具（Methods Writing Tool）说明书 · v2

一个 Tauri v2 桌面应用，把 Obsidian 里的「方法笔记」经"脚本 + AI"流水线，逐步变成可投稿的 Methods 正文。 核心理念：**脚本做确定性的活（抽取、制表、比对、加粗、归档），AI 做语言的活（改写、缝合）；一步一脚本，互不串扰。**

> **v2 更新摘要**（详见第六节）：step6 原文句改从笔记目录收集、句号计数与工具名检测修复（含从 ① 参数表抽工具白名单）、step6 不再依赖 ③；相似度脚本新增"整篇最终统计"模式（`mode=final`）；archive ③ 标签纠错为"改写+相似度"；改写约束辞典 `COHESION_02` 删除与去 AI 辞典冲突的 `Additionally,`。

## 三、工作流程（按顺序）

下面是 methods 管线从笔记到定稿的完整流程。**每一步：脚本做什么 → 读哪里 → 写哪里 → 你做什么。**

### 阶段 0 · 准备

- **综述同步（step0b_sync）**：同步方法笔记的属性 / `## 逻辑链` 段，并把审核通过的原句分发进目标笔记。 读 `methods_method_notes_dir` + `methods_review_relay`。
    
    > ⚠ 分发落点存在 docstring 与代码不一致（`### 待归类` vs `## 待归纳`），见第六节·待处理 A。
    

### 阶段 1 · 参数表（① methods_empty_table_relay）

1. **识别大节（list_sections）**：扫描笔记，列出有哪些"大节"（方法的各小节，如 MR 分析、细胞培养…）。
2. **参数分析 / 元素抽取（step1a）**：选一个大节 → 拼 `methods_param_prompt_template` + 该节笔记 → 复制给 AI → AI 输出"元素清单"（`- 工具 ‖ 产出` 这类配对行）→ 你粘回 ①。
    - **配对铁律**：当"用某工具产出某结果"是一个动作（ggplot2→柱状图、pheatmap→热图），抽成**一个元素、保住配对**，绝不拆成独立的"工具/图表"两项（会错配）。
3. **制表（step1b_build_tables）**：把 ① 里每个 `# 大节名` 块的 AI 元素清单，就地转成 `## 非变量表` + `## 变量表`。幂等：已转过（无 `‖`）的块自动跳过。
4. **代码填充（step1b_code_fill）**：用代码自动填能确定的表项。读 `methods_code_fill_template`。
5. **你手动填表**：在 ① 的表里填"你的选择 / 默认表述"。

### 阶段 2 · 单节改写（step5 → ③ methods_scoring_relay_file）

- **单节改写（step5）**：选大节 → 脚本蒸馏 ① 该节表格（非变量全取、变量只取填了的）+ 拼本节笔记全部候选句 + `methods_rewrite_dictionary_file` + `methods_rewrite_prompt_template` → 复制给 AI。
    - AI 按指令注入 `# 大节名` 标题，输出**五方案谱系**：A 贴源直改 / B 句式微调 / C 语态动词（单源）→ D 跨源合成 / E 合成精炼（多源）。
    - 你把五方案表**粘进 ③**（逐节累积）。 读 `methods_empty_table_relay`(①) / `methods_notes_folder` / 上述指令 + 辞典。

### 阶段 3 · 相似度核查（相似度脚本 · 逐节模式，③ 内）

- **PMID 分配 / 相似度（methods_similarity_check，默认模式 / 不传 mode）**：读 ③，**逐节**（按 `# 大节名`）与本节笔记语料一对一比对：
    - 算**源覆盖率**（rewrite∩源 的实词 / 源实词）；
    - 在**英文表达列**和**最像源句列**就地**加粗 ≥4 词逐字串**（`**…**`）；
    - 报最像源句 + 源 PMID（按 PMID 去重，取 Top2 不同源）；
    - 保留所有单节（累积痕迹）。 读 `methods_scoring_relay_file`(③，回退 ④) / `methods_notes_folder`。
- **你挑定**每节最终句（看加粗多少、覆盖率高低选最干净的），**累积进 ④**。
    - 想让逐字串信号继续往后传，就把**带 `**` 的句子**存进 ④。

### 阶段 4 · 整篇缝合（step7 → ④ 的 `# 最后选择`）

- **整篇缝合（step7_stitch）**：读 ④ 草稿 + `methods_stitch_prompt_template` + `methods_rewrite_dictionary_file` → 复制给 AI。
    - AI 只做**连贯性抛光 + 轻量打断**（连词 / 过渡 / 主语 / 动词轮换 / 打断可断的逐字串），**不改技术内容、不改步骤顺序**。
        
    - 输出固定骨架：
        
        ```
        # 整篇缝合
        ## 缝合后草稿        ← 去掉所有 **、过去时、第三人称
        ## 缝合和修改意见     ← 1–2 句总述 + 逐条对每个 ** 加粗的处理
        # 最后选择           ← 空标题，留给你
        ```
        
    - 你把整块粘回中转站，在 **`# 最后选择`** 下填入综合后的定稿（改 AD 之类内容、降 robust 等）。 读 `methods_rewrite_file`(④) / 缝合指令 / 改写辞典。
        

### 阶段 4b · 整篇相似度复核（相似度脚本 · final 模式，④ 内）【v2 新增】

- **整篇最终统计（methods_similarity_check，`params_json = {"mode":"final"}`）**：在 `# 最后选择` 填好定稿后运行：
    - 读 ④ 的 **`# 最后选择`** 正文，与 `methods_notes_folder` 全语料比对；
    - 出**整篇重叠比例**（最终稿实词被源语料覆盖的比例）+ 数出残留 **≥4 词逐字串**处数，并把它们就地**加粗**；
    - 生成 `# 整篇相似度统计` 块写回 ④（含一句话总述 + "加粗视图"，仅供核查）。
    - **不污染 `# 最后选择` 本身**（加粗只在统计块内）；幂等重跑不叠加；保留 ④ frontmatter。
    - 读 `methods_rewrite_file`(④) / `methods_notes_folder`。
- **触发约定**：前端"整篇统计"按钮调本脚本时 `params_json` 设 `{"mode":"final"}`；普通逐节那颗按钮**不传** mode（走阶段 3）。`mode` 也接受 `最后选择` / `whole` / `整篇`。

### 阶段 5 · 草稿评估（step6，报告写回 ④）

- **草稿评估（step6_evaluate）**：取 ④ 的 **`# 最后选择`** 正文（为空则回退旧"连贯版"/最长段）+ `methods_polish_dictionary_file` →
    
    - 脚本确定性检测：AI 高频词 / 时态 / There be 句首 / **工具名一致性（含从 ① 参数表抽白名单，覆盖 pheatmap/limma 等全小写工具）** / 占位符 / we 等；句级标注（句号计数已排除小数点）；
    - **句式对比原文句**：直接从 `methods_notes_folder` 按 `### 大节` 收候选句（v2：替代已废弃的 ③ `# 分配结果` 槽位），喂进 AI 评估 prompt；
    - 报告 `## ⚡ 脚本自动检测（Step 6）` 写回 ④（`##`/`###`，不带 `#` 一号标题；重跑前自动剥旧报告）。 读 `methods_rewrite_file`(④) / `methods_empty_table_relay`(①，抽工具白名单) / `methods_notes_folder`(原文句) / 去AI辞典 / 改写辞典。
    
    > v2：step6 **不再读 ③** `methods_scoring_relay_file`，也不再把它列为必需键。
    

### 阶段 6 · 归档（archive，清空中转站）

- **任务归档（methods_archive）**：在 `archive_folder` 扫描标了「历史归档: true」的笔记作为落点 →
    - **追加写**（保留笔记原有正文，本次归档续在后面，不覆盖）；
    - 每个中转站作 **`# 一号标题`**（① 参数表 / ② R代码 / **③ 改写+相似度** / ④ 改写评估），其下内容**整体下移、包在本站内**（出现 `#` 时降到 `##`；本就 `##` 不再多降；跳过代码块）；
        
        > v2：③ 标签已从旧术语"③ 评分分配句型"纠正为"③ 改写+相似度"。
        
    - 「历史归档」改回 false；
    - **仅在确实写入了有内容的中转站后**，才清空 ①②③④（防止"清了却没归档"）。 读 `archive_folder` / ①②③④。

## 四、关键约定（贯穿全流程）

- **`# 大节名`**：① 与 ③ 的分块锚。step5 注入、相似度按它逐节一对一比对，必须严格同名。
- **`# 整篇缝合` / `## 缝合后草稿` / `## 缝合和修改意见` / `# 最后选择`**：缝合输出与定稿的固定结构；step6 与相似度 final 模式均优先读 `# 最后选择`。
- **`# 整篇相似度统计`**【v2 新增】：相似度 final 模式写回 ④ 的统计块；内含"加粗视图"仅供核查，**勿覆盖回 `# 最后选择`**。
- **`**…**` 加粗 = 与文献逐字重合**（脚本算出），**不是强调**。缝合 / 评估都按"固定术语保留、普通叙述打断"处理，成稿去掉 `**`。
- **归档**：每个中转站 = `# 一号标题`，内容下移封在站内；追加不覆盖。
- **时态 / 人称**：Methods 一律过去时、第三人称（无 we）；详见改写约束辞典 RULE_01 / RULE_03。
- **找待处理笔记口径**：以 `待处理: true` 或 `批量: true` 为准（list_sections / step1a / step5 / similarity / step6 已统一）。
