# 图像辞典

## 归一化原则

> 本辞典按**视觉形态**归一化图形名称，不绑定具体方法——同一种图可服务多个方法。用途：让 AI 为「常用图形」列对号入座，而非自由命名。AI 只判断"这张图长什么样"，不判断"它来自什么方法"。定义的重点不是写全，而是写出与相似图形的差异，以此压住命名漂移。名称一律不含特殊符号。新图形由脚本自动追加到表格顶部（定义留空，待人工补全）。

## 图形定义

| 图形名           | 定义（画的是什么 + 视觉形态 + 与近邻的区分特征）                                                                                                              |
| ------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| 棒棒糖图          | 横轴为统计显著性指标（如−log10(P值)）、纵轴为条目名称（如通路或基因），用圆点标记各条目位置并以线段连接至基线，圆点大小常编码基因数或样本量；区别于条形图，它以点+线替代填充条形，视觉更简洁且适合条目较多的排序展示。                         |
| 免疫荧光          | 利用荧光标记抗体展示目标蛋白在细胞或组织切片中的空间分布与亚细胞定位，以不同颜色荧光区分蛋白与细胞核/细胞器等结构；区别于免疫组化，它以荧光信号而非显色沉淀呈现定位，且可在共聚焦显微镜下实现多通道叠加与三维层析。                               |
| 基因热图          | 行表示基因、列表示样本的二维矩阵，以颜色梯度编码基因表达量高低，常伴随样本或基因的层次聚类树；区别于普通热图，它专用于展示基因表达谱数据，行列分别为基因和样本。                                                         |
| 样本的层次聚类树      | 以树状分支结构展示样本间的相似性关系，分支长度反映样本距离，常配合性状注释条带使用；区别于基因聚类树，它聚焦于样本层面的分组验证而非基因层面的模块划分。                                                             |
| 软阈值筛选         | 横轴为软阈值幂参数、纵轴为无标度网络拟合指数或平均连接度的折线图，用于确定加权基因共表达网络分析的最优参数；区别于普通折线图，它专用于展示网络拓扑性质随阈值变化的趋势并标注最优阈值点。                                             |
| 基因聚类与模块划分     | 上部为基因层次聚类树、下部为彩色模块分配条带的组合图，将基因按表达相似性分入不同颜色模块；区别于样本聚类树，它展示基因层面的模块归属而非样本层面的分组关系。                                                           |
| 模块-性状关联热图     | 行表示基因模块、列表示性状或表型的矩阵热图，每个单元格颜色编码模块特征基因与性状的相关性强度，常标注相关系数和显著性；区别于普通热图，它的行列分别为模块和性状，核心语义是模块-表型关联。                                            |
| Circos 图      | 圆形布局，外圈为染色体或分类弧段，内部叠加多圈层数据轨道并以弧线连接不同节点，用于基因组或通路的全局环状展示；区别于弦图，它有多圈层数据轨道且外圈为固定分类结构，而非仅两两互连。                                                |
| 降维基因分布点图      | 在降维坐标空间（如UMAP/t-SNE）中，以点阵形式展示基因或分子在细胞簇上的表达分布，颜色深浅编码表达量高低；区别于降维散点图，它聚焦于单个基因的空间表达模式而非细胞分群聚类。                                               |
| 蛋白质三维结构图      | 展示蛋白质分子的三维空间折叠构象，以卡通带状或表面模型呈现α螺旋、β折叠及无规卷曲等二级结构，常按结构域或链段着色；区别于分子对接图，它仅展示单个蛋白的整体拓扑形态而非配体-蛋白复合物的结合细节。                                       |
| Ramachandran图 | 横轴为Phi角、纵轴为Psi角，以散点分布展示蛋白质主链二面角的空间位置，背景按允许程度分色区域（最适区、额外允许区、一般允许区、不允许区），用于评估主链构象的立体化学合理性；区别于散点图，它的坐标轴为固定的二面角参数且背景带有预设的允许区域色块。             |
| ERRAT图        | 横轴为残基编号、纵轴为错误率百分比，以柱状图展示滑动窗口内残基间非键相互作用的错误率，常标注95%和99%置信阈值线，黄色或红色柱表示超出阈值的质量异常区域；区别于柱状图，它专门用于蛋白质结构验证且带有统计置信阈值参考线。                          |
| ADMET性质评估图    | 横轴为拓扑极性表面积（TPSA）、纵轴为计算脂水分配系数（WLOGP或logP），以散点展示化合物在二维理化空间中的分布，常以椭圆或色块标注类药可接受区域（如Lipinski规则空间），用于快速判断化合物的口服成药性；区别于散点图，它以预设的类药空间边界作为核心判读依据。 |
| 花瓣图           | 以圆心为中心向外辐射多个花瓣状扇形区域，每个花瓣代表一个节点或类别，花瓣长度或面积编码该节点的度值或重要性大小；区别于饼图，它强调各元素与中心的关联程度及相对大小而非占比构成。                                                 |
| LASSO交叉验证曲线   | 横轴为log₂(λ)或-log₂(λ)，纵轴为部分似然偏差或均方误差，曲线展示不同正则化参数λ下模型的拟合误差变化，通常以误差棒表示标准误，并以虚线标注最优λ值；区别于普通回归拟合曲线，它专门用于展示LASSO正则化过程中通过交叉验证选择最优惩罚参数的动态趋势。      |
| LASSO系数路径图    | 横轴为-log₂(λ)或λ值，纵轴为各变量的回归系数，每条彩色曲线代表一个变量的系数随正则化强度变化的路径；区别于普通折线图，它专门展示LASSO回归中变量系数随惩罚参数增大而逐渐压缩至零的筛选过程。                                     |
| 泳道图           | 以多个水平或垂直泳道（带状区域）表示不同分类维度，每个泳道内以条形块或色块展示条目数量或富集程度，常用于并列展示多组通路或类别的排名结果；区别于条形图，它以泳道分区实现多维度并列比较而非单一序列排序。                                     |
| 雷达图           | 以多个等角辐射轴构成多边形网格，每个轴代表一个评估维度，数据点在各轴上的取值连接形成多边形面积，用于展示多指标综合评分；区别于柱状图，它通过封闭多边形面积直观呈现多维数据的均衡性与整体轮廓。                                          |
| 分子结构图         | 展示化合物分子的二维或三维化学结构式，标注原子、化学键及官能团；区别于通路图，它展示单个分子的拓扑结构而非多个分子间的反应流程。                                                                         |
| 毒性雷达图         | 以雷达图形式展示化合物在多维度毒性终点上的活性概率或评分分布，各轴为不同毒性指标；区别于传统折线图，其多轴呈中心放射状，面积大小综合反映毒性谱宽窄。                                                               |
| 分子对接图         | 展示小分子配体与靶点蛋白活性口袋结合的三维空间构象，通常标注氢键作用力、关键结合残基及结合位点细节；区别于通路图，它聚焦于单个复合物的微观空间结构而非宏观级联反应。                                                       |
| 散点图           | 两连续变量的点分布图，点的位置编码数值关系，可含拟合线、置信区间或分组着色（含 PCA/PLS-DA 得分图、MA 图）；区别于气泡图，点的大小不编码第三变量；区别于降维散点图，它的坐标轴有明确物理含义、点的位置可解读。                           |
| 降维散点图         | 二维平面上按降维坐标（t-SNE/UMAP/PCA/diffusion map 等）排列的点云，点按分群着色形成离散簇团，或按连续表达量着色（即特征图）；坐标轴无物理含义、点的绝对位置无意义；核心视觉特征是"色块簇团的聚散"而非位置关系。这是与散点图的形态级区别。     |
| 点图            | 行为基因、列为分群（或反之）的网格，每格一个圆点，大小编码表达百分比、颜色编码平均表达量；区别于气泡图两轴均为离散分类；区别于热图，它用圆点而非填色方格。                                                            |
| 气泡图           | 横轴连续量（富集比例/基因数/效应值）、纵轴分类条目，气泡大小编码一变量、颜色编码另一变量（常为显著性）；区别于散点图，它是大小+颜色双编码。                                                                  |
| 火山图           | 横轴 log2 fold change、纵轴 -log10 p 值的散点，显著上下调分色、不显著点灰色；两轴固定为效应量与显著性。                                                                        |
| 流式散点图         | 双参数荧光强度的点云，常分十字象限标注比例；区别于普通散点，它有固定的象限划分。                                                                                                 |
| 蜂群图           | 散点沿分类轴抖动排列、点不重叠呈蜂群状；以散点本身为主体，无箱体。                                                                                                        |
| 空间表达图         | 组织切片物理坐标上的点/像素，颜色编码表达量或细胞类型，背景常为组织轮廓；区别于降维散点图，它有可辨识的组织结构而非无意义坐标。                                                                         |
| 轨迹图           | 降维点云上叠加贯穿的有向曲线或分支树，颜色常编码拟时间；有向轨迹线是图形主体语义，非辅助标注。                                                                                          |
| 柱状图           | 分类轴对应数值高度的竖条或横条，可含误差线、堆叠、按大小排序（含瀑布图）；横轴是离散分类而非连续区间。                                                                                      |
| 箱线图           | 每组一个箱体表示四分位数加中位线与须，常叠加散点；用于多组分布对比。                                                                                                       |
| 小提琴图          | 每组一个对称的核密度轮廓，宽度表示密度，常叠加箱线或散点；区别于箱线图，用连续轮廓而非箱体，可显双峰。                                                                                      |
| 山脊图           | 多组核密度曲线沿纵轴错开堆叠，每组一条单侧填充曲线；区别于小提琴图，它单侧且纵向层叠。                                                                                              |
| 折线图           | 点以线段连接，横轴为有序变量（时间/剂量/序列），含校准曲线、色谱图、蜘蛛图等；区别于散点图有连线，区别于 KM 曲线非阶梯状。                                                                         |
| 热图            | 行列网格按数值着色的矩阵，常含聚类树；行列为样本/基因等异质对象。                                                                                                        |
| 相关性矩阵图        | 变量两两相关系数的对称方阵着色图，对角线为自相关；区别于热图，行列为同一组变量。                                                                                                 |
| 网络图           | 节点-连线结构，节点表实体、连线表关系，hub 居中或高亮。                                                                                                           |
| 通路图           | 带方向箭头的分子/反应流程示意，节点为基因或代谢物；区别于网络图，有明确方向与生物学流程语义。                                                                                          |
| 弦图            | 外圈分类弧段、内部以宽度不等的色带两两连接表示流量/权重；区别于 Circos 图，无多圈层数据轨道。                                                                                      |
| Circos图       | 圆形布局，外圈染色体/分类加多圈层数据轨道，圈内弧线连接；用于基因组环状全局展示。                                                                                                |
| 桑基图           | 两组或多组平行分类轴之间以流动色带连接，带宽表示数量；用于状态转换、组成流向。                                                                                                  |
| 树图            | 嵌套矩形按层级和数值填充着色，面积编码数量、颜色编码类别；区别于热图，矩形面积不等。                                                                                               |
| 韦恩图           | 多个交叠圆圈表示集合交并，交叠区标数量；适合少数集合。                                                                                                              |
| UpSet图        | 上部交集大小条形图、下部点线矩阵编码集合组合；区别于韦恩图，用矩阵而非交叠圆，适合多集合。                                                                                            |
| 富集条形图         | 横条长度表示富集显著性或基因数、纵轴为通路条目；区别于气泡图，仅条长单一编码。                                                                                                  |
| GSEA富集山峰图     | 上部运行富集分数折线呈山峰、中部基因命中竖线条码、下部排序指标渐变条，固定三段式垂直布局。                                                                                            |
| 曼哈顿图          | 横轴按染色体位置、纵轴 -log10 p 的散点，显著位点高出阈值线；用于全基因组关联。                                                                                             |
| 基因组浏览器轨道图     | 横轴基因组坐标，纵向堆叠多条信号轨道（peaks/信号/注释）；展示局部区域多层信号叠加。                                                                                            |
| 拷贝数变异图        | 横轴基因组坐标、纵轴 log2 ratio 或拷贝数，呈分段阶梯平台；区别于曼哈顿图纵轴非 p 值且为分段而非散点。                                                                               |
| 甲基化位点图        | 横轴 CpG 位点、每行一样本，填充圆（甲基化）空心圆（未甲基化）组成棋盘式二值矩阵；区别于热图，用二值圆点而非连续色阶。                                                                            |
| 森林图           | 每行一条目，点估计加水平置信区间线，常含 OR/HR=1 竖直参考线；用于效应量及区间对比。                                                                                           |
| KM生存曲线        | 阶梯式下降曲线，横轴时间、纵轴生存率，多组分色含 log-rank p。                                                                                                     |
| ROC曲线         | 横轴假阳性率、纵轴真阳性率的上凸曲线，含 AUC 值；用于诊断/预测模型评估。                                                                                                  |
| 游泳者图          | 每行一患者，横条长度表示治疗持续时间，条上标注事件符号；区别于森林图，展示时间跨度而非置信区间。                                                                                         |
| 列线图           | 多条平行刻度尺，每变量一条，连线读取总分与预测概率；视觉形态为平行刻度尺。                                                                                                    |
| 免疫印迹图         | Western Blot 条带扫描图，若干水平条带按蛋白和分组排列，常配灰度定量柱状图。                                                                                             |
| 凝胶电泳图         | 泳道中的核酸/蛋白条带图像，条带位置对应分子量；与免疫印迹图同族，但常为核酸且无抗体特异性。                                                                                           |
| 组织染色图         | 显微镜下的染色切片照片（HE/IHC/IF 等），用于形态或表达定位。                                                                                                      |
| 显微照片          | 细胞或组织的镜下照片（含荧光），无染色矩阵语义时的通用类别。                                                                                                           |
| 质谱图           | 横轴 m/z、纵轴相对丰度的离散竖线峰图；区别于折线图为离散竖线而非连续曲线。                                                                                                  |
| 示意图           | 人工绘制的机制/流程概念图，非数据驱动；用于研究设计或机制总结。                                                                                                         |
| 饼图与环形图        | 圆形按扇区面积/角度表示比例组成，环形图为中空变体；用于组成比例展示。                                                                                                      |

## 兜底规则

> 遇到本辞典未收录的图形：
> 
> 1. 归入形态最接近的已有名；
> 2. 组合图（如箱线图+散点、小提琴图+箱线）以**主体图形**命名，叠加元素在描述中注明；
> 3. 同一图形的三维变体（3D 散点、3D UMAP）归入对应二维条目；
> 4. 确实无法归入时，统一标 `[新增图形]`。脚本会把该新名自动追加到表格顶部，定义留空待人工补全。
