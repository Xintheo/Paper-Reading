# 引言写作辞典 v2.2

段落级叙事模式。**逻辑链层为「6 个对象」封闭集**——一段引言讲一个主导对象，逻辑链即该对象。对象层封顶 6 个、严格控制、不细分（再细 AI 与人都判不清，复杂度放元素端）。段内元素序列开放、逐段忠实记录。元素 ID 以元素辞典 v3.8 为准。

## 判定总纲：判整段立足点，不判单句出现了什么

**核心判据（贯穿 6 对象）**：判这一段的**立足点**——整段主要在讲什么、落点在哪个对象。段里黏到的其他对象（提到的通路、佐证的治疗、组成的分子）一律降为**属性**，不改变段落归属。

判据优先级（按序使用，前一条能判明则不启用后一条）：

1. **判主导对象（主）**：判段落主体围绕哪个对象展开。绝大多数段落由此判明。
2. **判终极落点（兜底）**：仅当主导对象不唯一（段落是真承转段，前半大量铺陈A、后半大量铺陈B）时启用，以该段**最终落在哪个对象**为准。

**本次研究是语义重心（理解，不是外加规则）**：判段落对象时，要理解一个内在事实——疾病/生物分子/机制通路/治疗方法/研究方法都是**领域共享的背景知识**（任何同领域论文都能写"某病发病机制""MR 原理""某分子致癌"）；只有**本次研究做什么、假设什么、选取什么作对象**，是这篇论文**独有的、别人写不了的特异内容**。所以一段话里只要实质落到"本研究采用 X / 我们假设 Y / 本研究选取 Z 作对象/靶点"，**这段的语义重心天然就在本次研究**——前面的方法原理、分子背景是为引出"所以本研究这么做"而铺垫的。据此该段主导对象判「本次研究描述」，**不切段、不被前面的背景铺垫稀释**。这是判语义判出来的（本研究是论文特异落点），不是规定"本次研究优先"这条规则去压它。

- 例：一段先讲"多组学+MR 是工具、MR 原理如何"，再讲"本研究采用此整合策略、我们假设…"——尾落本研究采用/假设，整段主导判「本次研究描述」（不因前半讲方法就判研究方法描述）。
- 反之，**整段纯讲方法本身**（原理/现状/适用/空白）、**完全不落到本研究采用** → 判「研究方法描述」。区别在这段最终有没有落到"本研究自己怎么做"。

否决式硬规则：

- **钩子/承转句不算落点转移**：末句出现"然而其机制不明""提示X可作为潜在靶点""值得进一步探究"等钩子式/承转式收尾，**不触发终极落点判据**。此类句子是叙事钩子，不改变整段主体归属。仅当后半段有实质性内容转向另一对象时，才启用终极落点。

通用守则：

- **判信息不判词**：不看段里出现了 however / pathway / treatment 等词，看整段在讲什么对象。
- **判主导对象**：一段若涉及多个对象，判哪个是立足点（段落主体围绕谁展开），归该对象；其余作段内元素记录。
- **关系方向是属性**：对象与疾病的关系（致病 / 保护 / 危险因素 / 预后），方向由元素/句子承载，**不影响对象归属、不另立对象**（不设"危险因素""保护因素"等对象）。
- **★双轨分立——对象定归属、元素定描述，各走各的路**：以上判的是**段落主导对象**（段落归属，第一轨）。它**只定段落归哪个对象，不限定段内句子能用哪些元素**（第二轨：句子视角从全集按语义选，见元素辞典）。所以一段判了「本次研究描述」，段内讲方法原理的句子照样标「方法原理与适用」、讲分子的句子照样标「分子与疾病关联」——**对象的描述是多样的，元素不被段落对象锁死**。正因为元素层能忠实接住每句的真实内容，段落对象判定才敢用"本研究是语义重心"这种强势收束（对象判粗无妨，句子视角会接住多样性）。两轨配套：一轨管归属（可强势收束），一轨管描述（必忠实多样）。

## 逻辑链（6 对象，封闭集，封顶不细分）

### 疾病描述

整段立足疾病本身——定义、分型、流行病学、负担、临床特征、发病机制（本病层面）、病程、难治性等。提到的治疗（"现有治疗仅对症"佐证病难治）、分子（"涉及某通路"）均为佐证背景，不改归属。

- **立足点**：这段在讲"这是个什么病、有多重、怎么发生"。
- **与治疗方法区分**：立足"病难治/严重"→ 疾病（治疗是佐证）；立足"治疗手段本身行不行"→ 治疗方法。
- **与机制通路区分**：发病机制依附于本病 → 疾病；机制系统本身是独立主角（可跨病）→ 机制通路。

### 生物分子物质描述

整段立足一个**可命名的单个实体**——基因 / 蛋白 / 受体 / 代谢物 / 化合物 / 药物（内源外源不分、致病保护不分，方向是属性）。讲它是什么、有何功能、与疾病有何关联。

- **立足点**：这段在讲"某一个分子/物质实体是什么、做什么"。
- **与机制通路区分**：主角是**点状单个实体**→ 本对象；主角是**一套系统/过程**→ 机制通路。实体提到的通路是其功能背景（属性）。
- **与治疗方法区分**：讲"它是什么"（分子本质）→ 本对象；讲"用它怎么治本病"（施用方案）→ 治疗方法。

### 机制通路描述

整段立足一**套可命名的机制系统**——信号通路（NF-κB / cGAS-STING / JAK-STAT）、程序性死亡（铁死亡 / 铜死亡 / 焦亡 / 自噬）、修饰方式（m6A / 甲基化 / 泛素化）、代谢过程等。讲这套系统如何运转、涉及哪些环节。组成它的分子是**部件**（属性）。

- **立足点**：这段在讲"某一套机制/过程系统如何运作"。
- **与生物分子区分**：系统过程 vs 点状实体（见上）。
- **与疾病区分**：机制作为独立系统（可跨病）→ 本对象；机制依附于某病的发生 → 疾病。

### 治疗方法描述

整段立足**用某手段对付本病**——药物方案 / 手术 / 放疗 / 器械 / 某疗法的现状、效果、局限，或论证某治疗候选值得用。提到的起效机制是说明（属性）。

- **立足点**：这段在讲"用什么手段治这个病、治得怎么样、值不值得用"。
- **与疾病区分**：立足治疗手段本身的评价 → 本对象；立足"病难治"（治疗只是佐证）→ 疾病。
- **与生物分子区分**：讲"用它怎么治"（施用）→ 本对象；讲"它的分子本质"→ 生物分子物质。
- **与研究方法区分**：治病的手段 → 本对象；做研究的工具 → 研究方法。

### 研究方法描述

整段立足**做研究用的方法/技术/工具/平台**——MR、多组学、机器学习、网络毒理、分子对接、测序等的原理、现状、适用或空白。注意：介绍方法本身的原理/现状/局限归此；若段末大量实质性内容落到"因此本研究采用X方法"，则以终极落点归入「本次研究描述」（钩子式收尾除外，见否决规则）。

- **立足点**：这段在讲"用什么方法/技术来做研究"。
- **与治疗方法区分**：研究工具（怎么研究）→ 本对象；治病手段（怎么治病）→ 治疗方法。
- **与本次研究区分**：终极落点在介绍方法本身的原理/现状/局限 → 本对象；终极落点在本研究的设计/方案/选用逻辑 → 本次研究描述。

### 本次研究描述

整段立足**本研究做什么**——研究目的、科学假设、研究设计、技术路线、研究对象选定、创新声明、研究方案（数据/样本/流程操作细节）、合规声明（伦理/注册，程序性）。从缺口转入本研究目的的"临门一脚"段亦归此。单独成段的纯合规声明归此。

- **立足点**：这段在讲"本研究要做什么、怎么做"。
- **与研究方法区分**：终极落点在本研究的设计/方案/选用逻辑 → 本对象；终极落点在介绍方法本身的原理/现状/局限 → 研究方法描述。
- **与生物分子/机制通路区分**：讲"本研究选取该分子/通路作为研究对象/靶点"→ 本对象；讲"该分子/通路本身是什么"→ 各归各。

## 关键边界焊点

1. **生物分子 vs 机制通路**：点状单个实体 vs 一套系统过程。主角是一个分子 → 分子；是一套通路/死亡方式/修饰 → 机制通路。黏连的另一方降属性。
2. **生物分子 vs 治疗方法**：讲"它是什么"（本质）→ 分子；讲"用它怎么治本病"（施用）→ 治疗方法。
3. **治疗方法 vs 研究方法**：治病手段 vs 研究工具。
4. **疾病 vs 治疗/分子**：立足治疗/分子本身 → 各归各；立足"病难治/严重"（治疗分子只是佐证）→ 疾病。
5. **本次研究 vs 研究方法**：以终极落点（兜底判据）为准，但钩子/承转句不算落点转移。最终落到"本研究采用X设计/选取Y靶点"且后半段有实质性内容转向 → 本次研究；最终落到"X方法在该领域有此空白/局限"→ 研究方法。
6. **疾病 vs 机制通路**：发病机制依附于本病 → 疾病；机制系统作为独立主角（可跨病）→ 机制通路。
7. **治疗策略 vs 靶点分子（判语义不判词，焊点）**：一段立足"该用某种治疗策略（如多靶点疗法）"、其中点了几个靶点分子（sortilin/clusterin 等）作论据 → **治疗方法描述**（立足治疗策略），靶点分子名作属性；不要被点到的分子名带跑去判生物分子。只有当整段主体确实是**讲某一个分子是什么/做什么**时才判生物分子。
    - 示例：AD 引言"多靶点药理学方法必要性 + sortilin/clusterin 作为治疗靶点 + 开发多靶点化合物是方向"——整段立足"AD 需多靶点治疗（策略）"，sortilin/clusterin 是论据 → **治疗方法描述**（非生物分子，尽管点了两个蛋白名）。

## 记观察（不强行焊，待实测积累后决定是否裂出）

以下为实测中已出现的灰区。暂不设硬性边界规则，AI 判属时以上述焊点 + 主导对象判据处理，标记后记录积累。

### 疾病现状 + 治疗局限混合开头段

段首铺陈疾病负担/现状，段中转入现有治疗手段的局限，末句可能引向"需新靶点"（→ 疾病）或"需新疗法"（→ 治疗方法）。见于文4段1、文9段1。 **处理**：以整段主导对象判定；末句若为钩子式收尾（"亟需新策略"类）不算落点转移，仍按主体判。若后半段有实质性治疗论证内容，启用终极落点兜底。

### 跨病借鉴

某治疗在别病成功 → 迁移至本病。低频。 **处理**：暂归治疗方法（手段本身仍是主角），不立新对象。积累跨篇案例后再决定是否裂出。

### 代谢物 vs 代谢过程

如 palmitate 分子 vs 脂质代谢过程。分子 vs 机制，极少数两可。 **处理**：以"点状实体 vs 系统过程"为判据判定，记录积累。

## 归类流程

1. 识别引言段落（按标题归一化定位 Introduction 区）。
2. 对每段：先**判主导对象**（段落主体围绕谁）。若主导对象不唯一（真承转段），启用**终极落点**兜底。钩子/承转句不触发落点转移。
3. 段内逐句标元素（描述动作，承载"怎么写这个对象"，由引言元素清单提供）。
4. 关系方向、黏连的其他对象 → 作段内元素/属性记录，不改段落对象归属。

> **逻辑链层已冻结（v2.2）。** 6 对象封顶，后续不增不细分。复杂度与迭代力量全部转入元素层建设。
