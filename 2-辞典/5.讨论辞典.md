# 讨论叙事辞典 v3.0.1

**段落位置 × 段落功能** 二维度判定：每段判一个**讨论位置**（3 个）和一个**段落功能**（14 个）。

**段落功能写死为主 + 极窄人工后门**：本辞典力求穷尽 SCI 讨论的段落叙事动作（14 个）。标注时优先归入现有 14 个；仅当某段叙事动作确实无法归入任何现有功能时，登记到「新发现」区供人工复核后手动加入，**不得为避免新建而硬塞进语义错位的现有功能**。新建命名 2-8 字，禁含具体疾病/分子/方法/药物/技术名。

## 讨论位置

描述该段在整篇讨论中的**物理结构位置**——开头 / 中间 / 结尾。只有 3 个，固定不积累。

**位置与功能解耦（核心原则）**：位置只看"这段处在讨论的哪个结构段落"，**不看它做什么叙事动作**（叙事动作由「段落功能」描述）。判位置时不纠结"它碰没碰本研究发现"——开篇段无论重申发现还是纯背景铺垫，都归开篇重申位置；具体做什么由功能区分。

**边界由两个切换信号锁定**（不靠功能白名单，避免重叠与硬塞）：

- **开篇 → 主线**：分界看"是否开始**针对某个具体发现展开论证**（解读/推机制/与文献交锋）"。
    - 真正的切换 = 开始针对具体发现展开；切换信号落在某段内部（哪怕后半句）该段整体即归主线。
    - **总括概述段留开篇（优先判断）**：若整段是总括式重述/概述本研究发现（功能为发现重申/发现概述、打包陈述结论），即归开篇——不因段内夹带的个别解释句而判进主线。判别顺序：先看整段是不是总括概述，是则留开篇；只有"前半背景、后半才首次针对具体发现展开"的段才按切换粒度进主线。例：阿特拉津/GDM 篇第1段整段总括全部发现（末尾顺带点机制方向），归开篇；其后段落针对具体发现展开，才进主线。
- **主线 → 收束**：分界看"是否转向**全文整体收尾**（整体局限/优势/意义/应用/展望），不再针对单个发现做新论证"。
    - 某段功能若是收束类五者之一（局限承认/优势声明/意义延伸/临床转化建议/展望收束），通常即进收束，不必等"However/limitations"显式词；收束类功能本身是收尾动作、不算机制论证，不得以"还在深化论证"为由留主线。
    - **仅认全文最后的收尾段（优先判断）**：收束类功能段若出现在**主线中段**、其后仍有独立的整体收束段（专门的 strengths/limitations/展望段），则它只是"机制导向应用"的主线延伸，位置归主线展开。判别要点：看该段之后是否还有专门的整体收束段——有则该段属主线（如 GDM 篇第4段药物靶点评估），无则进收束（如 ACOT8 篇第7段，其后仅局限段）。
    - **主线中段转化段例外（先于锚定判据判断）**：收束锚定只认**全文最后的收尾段**。若某收束类功能段（典型是临床转化建议）出现在**主线中段**——即其后仍有独立的、更典型的整体收束段（strengths/limitations/未来展望等专门收尾段）——则该段只是"把机制发现导向应用"的主线延伸，位置仍归**主线展开**。判别要点：看该段之后是否还存在专门的整体收束段；若有，则该段是主线延伸（如 GDM 篇第4段药物靶点评估，其后第5-7段才是 strengths/limitations/展望的真收束）；若无（该段已是讨论结尾、其后只剩同类收尾），才适用锚定判据进收束（如 ACOT8 篇第7段，其后仅第8段局限）。

### 开篇重申

讨论的**起手段**（物理开头，通常第 1 段，偶尔前 2 段，直到"开篇→主线"切换信号出现）。

- 不论重述发现还是先铺垫背景，只要在切换信号前，位置即归此；功能层再区分（重申发现→「发现重申」，纯背景起手→「背景综述」）。

### 主线展开

讨论的**中间主体段**（两个切换信号之间的所有段落），可多段。围绕发现与文献对话、推机制、解释差异，段间差异由段落功能区分。

### 收束总结

讨论的**收尾段**（"主线→收束"切换信号之后的段落，通常最后 1-2 段）。

- 转向对全文的整体收束——局限、优势、意义、应用、展望，不再针对单个发现展开新论证。

### 归并记录（以下旧位置名称已废弃，标注时不得再使用）

- 背景铺垫 → 主线展开（背景知识散在主线中、不单独成段时归主线展开；若是开篇起手的背景段则归开篇重申、功能标背景综述）
- 深化推断 → 主线展开（与主线展开边界模糊，统一归入主线展开；功能层用「机制串联」描述）

## 段落功能

描述该段内部的**叙事推进动作**。归一化判断标准：遮蔽元素序列，只问这段话的叙事推进动作是什么。同一篇论文不同段落可用相同功能名。段落功能不与讨论位置绑定，同一功能可出现在不同位置。

**一段多功能时取主导**：一段若含多个叙事动作（尤其短讨论的收束段，常把优势声明/局限承认/意义延伸/临床转化建议/展望收束揉在一段），段落功能只标**篇幅与分量上最主导的一个**；其余次要动作不在段落功能层重复标注，留待**阶段二元素层**逐句捕捉（元素层本就允许一段多个元素标签，信息不丢）。这符合"位置/功能粗、元素细"的分层设计。

> 命名说明：以下名称均已避开元素辞典元素名（如元素 H5「未来研究展望」≠ 本层「展望收束」、元素 H3「研究局限性」≠ 本层「局限承认」、元素 H2「临床转化启示」≠ 本层「临床转化建议」），防双链串扰。

### 重述与铺垫类

**发现重申** 直接重述本研究的核心发现，不展开解释，通常是讨论开篇第一句或独立短段落。

- 与"发现概述"区分：发现重申聚焦**核心**发现的重述（一两点）；发现概述系统罗列**多项**结果
- 与"发现阐释"区分：发现重申只陈述结论，不出现因果/推测连接词（because/this suggests/可能因为）

**发现概述** 把本研究多项发现系统性打包罗列或概述，不逐一展开解释。

- 与"发现重申"区分：发现重申是核心发现的简短重述，本功能是多项结果的系统罗列
- 与"机制串联"区分：发现概述只是平行罗列结果，不串联为因果链

**背景综述** 系统陈述研究对象的已知属性、机制或流行病学数据，为后续论证铺设知识背景。包括铺垫已知机制作为推断前提（原"机制引题"已归并于此）。

- **跨位置**：可出现在开篇（以背景起手）或主线（中途铺垫某机制前提），位置由其物理结构决定、不影响本功能判定
- 与"发现阐释"区分：背景综述讲既往已知（知识产权属他人/学界），发现阐释解释本研究发现
- 与"同向引证"区分：背景综述中性铺陈领域已知事实、不指向支持某结论；同向引证引文献是为支持本研究某个具体结论

### 文献对话类

**同向引证** 引用既往文献支持本研究发现，强化可信度，文献与本研究结论方向一致。

- 与"机制串联"区分：判断核心是**目的**——同向引证目的是借文献增信，机制串联目的是串因果链（两者都可能引文献）
- **引用密度不是判据**：一段即便密集引大量文献，只要目的是为本研究串联机制路径（A→B→C），归机制串联；只有当文献作用是"佐证本研究某个孤立结论"时才归同向引证
- 与"背景综述"区分：同向引证服务于支持本研究某结论，背景综述是中性铺陈已知

**异向辩驳** 正面反驳与本研究矛盾的文献，论证本研究结论更可靠。

- 与"异向求和"区分：辩驳主张"我方更可靠"（however our data show…more reliable）；求和归因差异、不评判对错
- 信号锚：however / in contrast，且落点是"本研究证据更强"

**异向求和** 承认与既往文献结果不一致，通过归因寻求合理解释，不评判对错。

- 与"异向辩驳"区分：求和的论证目标是"差异可被合理解释/双方各有道理"，不主张谁更可靠
- 信号锚：the discrepancy may be due to / 这种差异可能源于

### 推断类

> **推断类三分核心判别（发现阐释 / 机制串联 / 假说提出）**：三者都"串因果",区别只看**因果链的归宿**，不看环节多少、不看引用多少：
> 
> - 链是**解释某个单一发现/观察为何如此**的手段 → **发现阐释**（哪怕串了 3-4 个环节，只要整段服务于解释一个发现）
> - 链被**提炼为一条脱离单一观察、可独立陈述的通路/模型主张** → **机制串联**（整段把多发现/多系统串成独立贯穿路径）
> - 链**升华为一个本研究新提的整合模型/普适新假说**（loop、feed-forward cycle 等） → **假说提出**（取末尾新模型为落点高潮，不取铺垫的串链部分） 正反例：「观察到 ACOT8 升高→推测它释放棕榈酸致害」链是解释手段=发现阐释；「代谢应激→DNA释放→cGAS-STING→synergistic loop」末尾升华出新 loop 模型=假说提出。
> 
> **区分锚点（定义为主；当三者模糊难分时，用锚点快速倾向，不取代上方归宿定义）**：
> 
> - 倾向**机制串联**：出现 "a model / a disease model / a framework / a pathway whereby" 等把证据收拢成一个**命名结构**的表述（如 GDM 篇第3段 "support a disease model in which…"）。
> - 倾向**假说提出**：出现 "synergistic loop / feed-forward cycle / a broader mechanism whereby" 等**本研究新创的循环或普适命题**。
> - 倾向**发现阐释**：无上述结构化/新创表述，整段只是用 may/could/likely 解释某一个发现为何如此。
> - 限定：锚点用于在推断类三者之间快速切分；若整段叙事方式本就明确属于他类（如通篇局限承认、仅顺带引用他人 model），以明显叙事动作为准，锚点不夺权。

**发现阐释** 在重述基础上展开解释"为什么会这样"，可含机制推测，但聚焦解释**单个发现本身**为何如此。

- 与"发现重申"区分：发现阐释出现因果/推测连接词并展开解释
- 与机制串联/假说提出区分：见上方「推断类三分核心判别」

**机制串联** 将多个证据或发现串联为一条可独立陈述的因果通路（A→B→C 跨多对象），而非围绕单一发现解释。

- 与发现阐释/假说提出区分：见上方「推断类三分核心判别」

**假说提出** 基于本研究结果，向上提出一个全新的假说、机制模型或更一般的科学主张，超出"解释本结果"的范围（our findings point to a broader mechanism whereby…）。

- 与发现阐释/机制串联区分：见上方「推断类三分核心判别」

### 收束类

**局限承认** 承认本研究的不足及其对结论的影响边界。

- 与"优势声明"区分：互为镜像（不足 vs 长处）
- 与元素 H3 区分：本功能是段落级叙事动作，元素辞典 H3「研究局限性」是句子级元素，分工不同名

**优势声明** 主动陈述本研究相对既往研究的方法或设计优势。

- 与"局限承认"区分：互为镜像
- 与"异向辩驳"区分：优势声明是自陈长处（不针对具体矛盾文献），辩驳是针对矛盾文献的反驳

**意义延伸** 从核心发现延伸到科学知识体系层面的意义（理论贡献、领域影响）。

- 与"临床转化建议"区分：意义延伸讲**科学/理论**意义，临床转化建议提**具体应用/治疗/防控**方向
- 与"展望收束"区分：意义延伸讲"这发现有何价值"，展望收束讲"接下来该研究什么"

**临床转化建议** 基于发现提出具体的临床应用、治疗方向、防控或政策建议。

- 与"意义延伸"区分：本功能落到**可操作的应用建议**，意义延伸停留在科学意义层面
- 与元素 H2 区分：本功能是段落级叙事动作，元素辞典 H2「临床转化启示」是句子级元素，分工不同名

**展望收束** 提出未来研究方向或尚待解决的科学问题，收束全文。

- 与"意义延伸"区分：展望收束指向"未来要做什么"，意义延伸指向"当前发现有何意义"
- 与元素 H5 区分：本功能是段落级叙事动作，元素辞典 H5「未来研究展望」是句子级元素，分工不同名（v2.0 由「研究展望」改名以避双链串扰）

## 速查表

|段落功能|核心动作|易混对（看鉴别点）|
|---|---|---|
|发现重申|重述核心发现，不解释|↔ 发现概述 / 发现阐释|
|发现概述|系统罗列多项结果|↔ 发现重申 / 机制串联|
|背景综述|铺陈既往已知|↔ 发现阐释 / 同向引证|
|同向引证|引文献增信（同向）|↔ 机制串联（看目的）|
|异向辩驳|反驳矛盾文献，我方更可靠|↔ 异向求和|
|异向求和|归因差异，不评判|↔ 异向辩驳|
|发现阐释|短链解释单个发现|↔ 发现重申 / 机制串联|
|机制串联|多证据串成因果长链|↔ 发现阐释 / 假说提出|
|假说提出|创造新机制/假说|↔ 机制串联|
|局限承认|认整体不足|↔ 优势声明|
|优势声明|陈方法/设计长处|↔ 局限承认 / 异向辩驳|
|意义延伸|科学/理论意义|↔ 临床转化建议 / 展望收束|
|临床转化建议|可操作应用建议|↔ 意义延伸|
|展望收束|未来研究方向|↔ 意义延伸|

## 后续积累方式

段落功能名称层已写死为 14 条。新论文标注时：

1. 判定每段的讨论位置（3 选 1，按功能边界）
2. 遮蔽元素序列，只看叙事推进动作，匹配到 14 条中最近的一条
3. 位置笔记按篇汇入「段落功能逻辑链」：`- (PMID: xxx) [[功能1]]→[[功能2]]→…`（双链，反映该位置内的谋篇走法）
4. **仅当**某段动作确实无法归入 14 条任一时，登记「新发现」区供人工复核——禁止硬塞
