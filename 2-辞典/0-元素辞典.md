# 元素辞典（摘要区定稿；引言区冻结：6对象 × 描述视角，均经多批新样本验证，治疗/机制视角已转正）

句子级功能标签。描述"这句话在做什么"。

> 摘要区结果元素由四收为三：「呼应印证」并入「单点呈报」（呼应/印证仅为发现附带的属性，不构成独立功能位，且回溯呼应对象难判易飘）。结果区现为单点呈报 / 多点综述 / 机制解读三元素。

## 总则

**元素层 = 逻辑链层的同质细分**（元素的尺子跟随该章节逻辑链层的尺子）：

- 逻辑链是**叙事**的章节（摘要、结论）→ 元素是**叙事动作**（陈述/解读/凝练…）。
- 逻辑链是**对象**的章节（引言、讨论，及将来结果）→ 元素是**对象的性质维度**（物理/化学/生物/与病关联…）+ 章节专属姿态。

**各章独立、各走各的**：每章按自己的逻辑把元素建全，拼 prompt 时只调本章这一套。

**统一命名即公共（隐式）**：不设"公共元素"显式分类。各章建完后，若两章某元素实质相同，起**相同名称**即可——Obsidian 双链自动合并为同一节点，"公共"是命名一致的副产品，无需额外结构。

**每个元素的字段**：名称 + 定义（填什么内容/做什么动作）+ 边界（与最易混元素的差分）+（可选）极简例子。"与X区分"行是定义的组成部分，不得移出。

## 一、摘要元素

> **组织：三相锚定 ×（对象概述 + 叙事动作）两类互补。** 三相（研究前/研究中/研究后）是位置锚，标定句子落在叙事流程的哪一阶段。其下挂两类元素——**对象概述类**（粗粒度描述某对象本身）与**叙事动作类**（推进研究流程的动作）。两类互补、合起来覆盖摘要任一句子。
> 
> **判定总纲：词触发优先 → 语义复核定案 → 词不单独定案。** 判一句归哪个元素，先用信号词快速缩小候选（这是人判断的自然方式，不必回避），再用语义确认落位。**信号词是第一优先级的触发线索**（thereby/in summary/we used/identified…把你引向某候选），**但最终由语义裁决**——词出现不等于命中、缺席不等于否定，词不单独定案。不"只看词"，也不"为回避看词而无视显见信号"。
> 
> **两候选并存时，锚定更收敛、确定度更高的那个。** 一句兼含两种功能时（如"用docking评估结合"=方法+目的），锚指向更收敛的一方：方法比目的收敛（一个目的有多种方法、一个方法指向的目的受限）→ 锚方法；具体发现比泛结论收敛 → 锚发现。其余成分降为伴随属性、不抢落点。各词条「与X区分」行是此总纲在具体边界上的落地。
> 
> **判落点、单标一个**：一句只标一个元素。一句串多个动作（"为探究X而整合多组学"）时，判语法主句的叙事落点，标那一个。
> 
> **颗粒度**：摘要走粗粒度。对象概述每类约 1 句级（可糅合多维），不细分性质——性质细分是引言的事。摘要"疾病概述"与引言"疾病描述"**共享同一对象边界**，仅颗粒度不同。

### 〔对象概述类〕落点在"概述某个对象本身"

**疾病概述** 语义落点是概括某疾病本身是怎么回事——它的负担、流行、严重性，或它如何发生（**含本病层面的发病机制**）。**某具体物质/毒素引发损伤的专属致病/中毒过程**（如"某毒素被吸收→抑制蛋白合成→致肝肾坏死"这条该物质特有的致病链）也归本元素——它依附于"这次损伤/中毒怎么发生"，不是可跨病通用的机制系统。

- 与机制通路概述区分：发病机制依附于本病、或某物质专属的致病/中毒链（绑定具体病/损伤）→ 本元素；一套机制系统本身如何运转、脱离具体某病也成立（可跨病通用，如程序性死亡、某信号通路本身）→ 机制通路概述。判"是否绑定具体病/损伤"：绑定 → 疾病概述，可跨病通用 → 机制通路概述。
- 与生物分子物质概述区分：语义主体是"病"（或致病过程）→ 本元素；语义主体是"某分子/物质实体是什么"→ 生物分子物质概述。

**生物分子物质概述** 语义落点是概括某可命名实体（基因/蛋白/受体/代谢物/化合物/暴露物）是什么、有何功能、或与疾病有何牵连。

- 与机制通路概述区分：语义主体是一个点状实体 → 本元素；语义主体是一套系统/过程 → 机制通路概述。

**机制通路概述** 语义落点是概括一套独立的机制系统（信号通路、程序性死亡、修饰、代谢过程等）本身如何运转——脱离具体某病也成立。

- 与疾病概述区分：独立机制系统（可跨病）→ 本元素；某病的发病机制（依附本病）→ 疾病概述。
- 与生物分子物质概述区分：一套系统过程 → 本元素；一个点状分子 → 生物分子物质概述。

**治疗方法概述** 语义落点是概括现有治疗手段的现状、效果或局限。

- 与疾病概述区分：语义在讲"治疗手段本身怎样"→ 本元素；语义在讲"病难治"（治疗只是衬托病情）→ 疾病概述。
- 与生物分子物质概述区分：讲"用它怎么治"→ 本元素；讲"它的分子本质"→ 生物分子物质概述。

**研究方法概述** 语义落点是概括某研究工具/技术的领域背景（如 MR、多组学、网络毒理的现状或适用性）。摘要中少见。

- 与方法步骤交代区分：泛泛交代某方法的领域背景 → 本元素；交代本研究具体用它做了什么 → 方法步骤交代（叙事动作）。

### 〔叙事动作类〕落点在"推进研究流程的某个动作"

**研究缺口与必要性** 语义落点是研究前为本研究铺垫动机——指出现有研究的空白/不足（"还缺什么、还不清楚、还不够好"），或主张开展本研究的紧迫性与价值（"所以亟待重新评估、有必要做"）。指出空白与主张该做是同一动机功能的两种说法，统归本元素，不再细分。

- 与对象概述类区分：语义落点是"研究动机"（为什么要做这研究），不是概括某对象本身。
- 与未来研究展望区分：研究前指出既有空白/必要性（动机）→ 本元素；研究后指出下一步该做什么（去向）→ 未来研究展望。判时间位：研究前是动机，研究后是去向。

**研究目的** 语义落点是陈述本研究的意图/要回答的问题（"旨在探究什么"），**纯意图、不含做法**。

- 与方法步骤交代/研究策略概述区分：语义只讲"想弄清什么"→ 本元素；语义一旦落到"用了什么做法/整合了什么"→ 方法步骤交代或研究策略概述（即便句子以"为了探究X"起头，只要重心在交代做法，就归方法类）。

**方法步骤交代** 语义落点是交代本研究用了哪些做法/步骤——只讲"做了什么"，**不带由该做法得出的发现**。一句兼含目的与方法时锚方法（目的作伴随属性，见总纲）。

- 步骤"在干什么活"作属性附着（供写作细看序列节奏，不另立元素）：预测类（毒性/ADMET/性质预测）／获取整合类（靶点预测、数据库交集、多组学整合）／富集通路类（GO/KEGG/PPI/富集）／建模评估类（ML建模、列线图、SHAP、性能评估）／实验验证类（in vitro/in vivo 验证）。
- 与结果区区分：语义只有做法、不带任何结果产出 → 本元素；一旦带出结果（哪怕同句也提了方法）→ 结果区（按呈现方式落元素）。判有无结果产出，不看有无方法名。
- 与研究策略概述区分：逐项具体做法 → 本元素；整体路线/编排逻辑 → 研究策略概述。

**研究策略概述** 语义落点是概括本研究的整体技术路线或设计编排（方法之间怎么组织），而非逐项步骤。

- 与方法步骤交代区分：宏观路线编排 → 本元素；逐项具体做法 → 方法步骤交代。

> **结果区三元素的共通底线与判据**： **底线——有方法的结果还是结果**：一句话只要在报一个本研究结果，不论它带不带方法名（MR / docking / ML / experiments…），都归结果区。方法名是属性，提了方法不改变它是结果。**信号词作触发线索、语义复核定案**（identified/showed/confirmed 把你引向"在报发现"，但落哪个结果元素由语义定）。 **与方法步骤交代的界**：纯交代做了什么、不带任何结果产出 → 方法步骤交代；一旦带出结果 → 结果区。判据是"有没有结果产出"。 **落具体（走指令结果块决策树）**：报单项发现（含带方法、带比较、带趋势、带印证/呼应措辞、同一干预的一组连带效果——这些都是属性）→ 单点呈报（兜底）；多个分别独立测得的发现收拢成一句 → 多点综述；推断未测得的机制 → 机制解读。

**单点呈报** 摆出本研究的单个发现本身——某对象有某性质、处于某状态、某数值、某干预产生某效果。**本类兜底元素**。以下都仍是单点呈报，相应信息作属性附着、不另立元素：

- 句中提了方法（"MR identified…"、"docking showed…"）——方法是属性（底线：有方法的结果还是结果）；
- 句中带比较/方向（"结合最强 −18.45"、"唯一支持的基因"、"最高贡献度"）——比较是属性；
- 句中带剂量/时间趋势（"剂量依赖升高"）——趋势是属性；
- 句中带实验印证或呼应措辞（"experiments confirmed X"、"consistent with…"、"in line with the transcriptomic data"）——印证/呼应只是该发现附带的属性，无论是首报还是与前文一致，都归本元素；
- 同一次干预产生的一组连带效果（"敲低后减少 X、降低 Y、改善 Z"）——同一干预自带的多项后果是一项发现的多维度，归本元素。
- 与多点综述区分：报单独一项、或逐项列举几项、或报一个富集发现（"这批靶点富集/参与氧化、炎症、凋亡等过程"——富集是一项发现，那串过程是其内容明细）→ 本元素；把**多个分别测得的发现**抽象收拢成一句概括 → 多点综述。

**多点综述** 把**多个分别测得的发现**收拢成一句概括（"各项分析均显示…"、"多个终点均改善"——每个发现是独立测得的，被一句话收拢）。

- 与单点呈报区分：收拢多个独立发现 → 本元素；报一项发现（含一个富集发现"参与多过程"、含同一干预的一组连带效果——那是单项发现的内容明细/多维度，不是多个独立发现）→ 单点呈报。判"是几个独立发现的收拢"还是"一项发现自带的多项内容"。
- 与结果凝练区分：本元素在结果阶段收拢同一批并列发现；结果凝练在结论阶段把全文主要发现压成一句总结。

**机制解读** 基于本研究发现，推断其背后的机制或因果关系（解释"为什么会这样"，是未直接测得的推断）。

- 与单点呈报区分：陈述测得的发现 → 单点呈报；由发现推断未测得的机制/因果 → 本元素。

**结果凝练** 语义落点是把本研究多项发现压缩成一句**事实性**总结，仍停在"发现"层面。

- 与核心论断区分：停在事实层（总结发现）→ 本元素；升到价值判断/主张 → 核心论断。

**核心论断** 语义落点是基于**本研究自己发现**给出的价值判断、立场或主张（升到"观点"层，如"X 是潜在治疗靶点"）。可前置到摘要开头（此时整篇逻辑链常为"结论先行"）。

- 与结果凝练区分：停在事实层（总结发现）→ 结果凝练；升到价值判断/主张 → 本元素。
- **结论区"总括 + 具体"两句式（焊点，防总括句漂移）**：结论区常见"先总括促进/影响、再点具体靶点/机制"两句。**总括性的事实总结句**（如"Atrazine 通过多靶点多通路促进 CRC 进展"——把全文发现压成一句事实）→ 结果凝练；**具体的价值主张句**（如"ABCC1 是连接暴露与进展的中心基因"——给出靶点定位/主张）→ 核心论断。若两句都是并列的价值主张（无总括事实句），则都标核心论断。判事实层 vs 主张层，不靠句子位置。
- **本研究产出 vs 领域既往（关键边界，防误收背景）**：这句内容**是不是本研究自己得出的产出**——是本研究结论/主张（哪怕前置在开头）→ 本元素；是研究开始前已确立的**领域既往已知事实**、引来作背景 → 对象概述类（疾病概述/生物分子物质概述等）。has shown / we identify / demonstrates 等是触发线索、不单独定案：见到先看"产出还是既往"，由语义裁决。例："本研究证明 X 是 Y 的靶点"是产出 → 核心论断；"既往证据显示 X 能预测 Y"是领域共识作背景 → 生物分子物质概述。

**研究创新点** 语义落点是给本研究做价值定位，强调方法/视角/对象上的新颖性或首次性。

- 与研究目的区分：想做什么（意图）vs 做出来新在哪（定位）。
- 与临床转化启示区分：学术/方法层面的新颖 vs 对临床应用的价值。

**临床转化启示** 语义落点是陈述结果对临床实践、政策或转化应用的意义。

- 与核心论断区分：对发现本身的主张 vs 指向临床/应用的价值去向。
- **★防被核心论断误并（焊点）**：句子落点在**应用去向**（"为预防/干预提供靶点""highlight the potential to mitigate/treat""provide a framework for…application""guide preventive strategies"）→ **本元素**；落点在**对发现本身的定位/主张**（"X 是关键靶点""X 是中心基因""X 介导 Y"）→ 核心论断。常见结尾句"These findings provide insights / reveal promising targets **for prevention and intervention**"——落点在应用去向，标**临床转化启示**，不要并入核心论断。一句若兼有主张+应用去向，按该句**主导落点**取一个：纯靶点定位→核心论断；明确指向临床/转化用途→临床转化启示。

**未来研究展望** 语义落点是指出本研究之后下一步该做什么、尚待验证什么。

- 与研究缺口与必要性区分：研究前指出既有空白/必要性（动机）vs 研究后指出未来方向（去向）。

## 二、引言元素

> **组织：6 对象（封闭，同引言辞典）× 各对象的「描述视角」元素。** 引言是**对象逻辑**——逻辑链层判整段主导对象（疾病/研究客体/机制通路/治疗方法/研究方法/本次研究），**这是底线，元素层不改变段落归属**。元素层只标"这个对象**被从哪个侧面（视角）描述**"。
> 
> **元素 = 描述视角，不是描述手法**：视角是"从哪个内容侧面看这个对象"，不是修辞句式。**视角随对象变**，各对象下独立焊，同名不共享。
> 
> **判落点单标一个**：一句标一个视角元素。
> 
> **元素名洁净**：所有视角元素名不含 `/`、`\`、`（）()`、`:` 等符号。
> 
> **判语义为主、词作触发线索**：词触发、语义定案、词不单独定案。

### 〔通用视角〕任何对象段都可挂

**研究现状与缺口** 描述"针对该对象，现有研究/认知到了什么程度、还缺什么、有何争议"。

- 与各对象专属视角区分：描述对象**本身的某侧面**→专属视角；描述"对该侧面的**研究够不够**"→本元素。

### 〔疾病〕描述视角（样本足，焊死）

**疾病负担与流行** 发病率、患病率、死亡率、社会经济负担、趋势。

**疾病临床特征与分型** 疾病的定义、症状、分期分型、病程、可逆性、临床异质性。（疾病系不另设"定义与归类"，定义句一律归此。）

**疾病发病机制** 本病如何发生（本病层面的病理生理、致病环节）。

**疾病危险因素与病因** 导致促进本病的因素、暴露、诱因。

**疾病治疗现状佐证** 疾病段内用"现有治疗仅对症/难治"佐证病情严重或未满足需求（段落主导仍是疾病）。

#### 〔研究客体〕描述视角（样本足，焊死）

> **对象边界**：立足某个被研究锁定的**生物学客体**——涵盖一切可命名的、被当作研究焦点的生物学事物：基因/蛋白/受体/酶/代谢物/化合物/暴露物/毒素/**细胞类型/组织/器官/病毒颗粒/菌群**等。对应引言三件事第②步"把疾病收窄到的研究焦点"中的**实体焦点**一支。
> 
> **★类型下放（封死对象层敞口的定死条款）**：客体的**具体类型**（分子？细胞？组织？器官？病毒？）**不在对象层区分**，一律统归本对象；类型区分由**关键词三级分类**承担（具体基因和蛋白/具体物质/具体细胞与组织器官/…）。对象层只问"这段是不是立足某个研究客体在描述"，不问"它属哪类实体"。故无论引言聚焦分子、细胞、组织还是病毒，段落主导对象都判「研究客体描述」，**绝不因实体类型新增对象**。本条把"客体类型"这条天然开放的轴移出对象层，保障"6 对象封闭"。

**客体定义与归类** 描述该客体是什么、属于哪类、结构/形态/所在部位。

- 与机制通路区分：点状客体实体→本视角；一套系统过程→机制组成与运转。

**客体来源与分布** 描述其来源（内源/外源/天然/环境）、表达分布、所在解剖部位、暴露途径。

**客体理化性质** 描述物理/化学性质、稳定性、ADMET/药代毒理性质。（多用于分子化合物类客体；细胞组织类客体此视角常空，不强标。）

**客体生理功能** 描述其正常生理功能、生物学作用、所处功能状态（如细胞的收缩表型）。

**客体与疾病关联** 描述该客体与疾病的关联——致病/保护效应、暴露-效应、其状态改变或功能失调驱动病程、作为标志物/靶点的关联证据。

- 内涵专属：本对象的"关联"是"该客体本身致病/暴露/标志/其失调驱动病程"；与机制对象的"参与发病"不同名共享。

**客体候选价值** 描述其作为研究对象/靶点/候选物的价值与理由（为何值得研究它/为何值得作干预靶点）。

#### 〔机制通路〕描述视角（已验证，焊死）

**机制组成与运转** 该机制系统由哪些环节部件组成、如何运转。

**机制调控** 该机制如何被调控——上下游、反馈，及基于该机制的干预方向。

- 与治疗候选论证区分：立足"调控该机制系统本身"→本视角；立足"某治疗手段值得用"→治疗候选论证。

**机制与疾病关联** 该机制系统参与哪些疾病的发生发展。

- 内涵专属：机制的"关联"是"参与发病/驱动病程"，与客体的"关联"不同。

#### 〔治疗方法〕描述视角（已验证，焊死）

**治疗现状与局限** 现有治疗手段的现状、疗效、局限、未满足需求。

**治疗候选论证** 某治疗手段/候选为何值得用、起效依据。

#### 〔研究方法〕描述视角（样本足，焊死）

**方法原理与适用** 某研究方法/技术/工具/平台的原理、能做什么、适用范围。

**方法现状与空白** 该方法在本领域的应用现状、优势、或尚未被用于此的空白。

- 与本次研究区分：终极落点在介绍方法本身→本视角；落点在"本研究采用X"→本次研究对象。

#### 〔本次研究〕描述视角（样本足，焊死）

**研究目的与假设** 本研究的目标、要回答的问题、科学假设。

**研究对象靶点选定** 本研究选取了哪个客体/通路/人群作为研究对象或靶点。

**研究设计与方案** 本研究的技术路线、数据样本、流程操作、整体设计。

**研究合规声明** 伦理审批、注册等程序性声明。

#### 引言视角全集（23，封闭）

疾病〔疾病负担与流行、疾病临床特征与分型、疾病发病机制、疾病危险因素与病因、疾病治疗现状佐证〕；**研究客体〔客体定义与归类、客体来源与分布、客体理化性质、客体生理功能、客体与疾病关联、客体候选价值〕**；机制通路〔机制组成与运转、机制调控、机制与疾病关联〕；治疗方法〔治疗现状与局限、治疗候选论证〕；研究方法〔方法原理与适用、方法现状与空白〕；本次研究〔研究目的与假设、研究对象靶点选定、研究设计与方案、研究合规声明〕；通用〔研究现状与缺口〕。

#### 引言元素增量规则

- 逻辑链层（6 对象）封闭，不新建。
- 元素层（描述视角）开放但受控：遇现有视角语义确实装不下的句子，在「新发现-新元素」块提议，注明所属对象 + 首次 PMID；人工审核后才入辞典。
- 受控门槛：①现有视角语义确实装不下②守互补互斥③最好跨篇出现再立。
