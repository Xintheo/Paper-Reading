# 引言写作辞典 v1.3

段落级叙事推进模式，名称归一化，序列积累在对应笔记中。增量式扩充。所有内容来自已分析的论文与领域常识，名称层受控扩充。

**版本说明（v1.2 → v1.3）**：①改名——逻辑链「研究历史沿革」与元素辞典 v3.4 的 C7「研究历史沿革」完全同名，会导致 Obsidian 双链在段落级链笔记与句子级元素笔记之间串扰，故改为「历史脉络引题」（定义与典型序列不变）。②扩充一条——补「文献证据梳理」，填补 C 层"跨多研究证据综述"这一段落结构（既有 15 条中，单一因素归影响因素深入、静态疾病背景归疾病背景铺垫、时间线归历史脉络引题，均覆盖不到"主题级证据格局综述"）。由 15 条增至 16 条。其余 14 条名称与定义未改动。逻辑链名称与元素辞典、结果辞典名称不重复（已查重：16 条与元素辞典 67 个元素名、摘要写作辞典 21 条均无重名）。典型元素序列为记录性参考，非归类依据——逻辑链归类只看段落叙事推进动作（遮蔽元素序列后判断）。元素 ID 的规范名称与定义以元素辞典 v3.4 为准。

**v1.1 → v1.2 历史**：专家预置扩充，由 13 条增至 15 条，补「缺口承转」「机制铺陈」；「合规声明」标注为程序性条目。

**v1.0 → v1.1 历史**：为每条逻辑链补充"典型元素序列"，引用元素辞典 v3.4 的元素 ID，使引言段与摘要段一样可视化逐句逻辑形状。

## 标题名称

归一化识别引言二级标题的各种写法，用于定位引言起始行。格式：归一化名称: 变体1, 变体2, ... 找不到匹配时手动添加变体。匹配时自动剥离序号（如 1. / 1.1 / (1) / 一、等）。

Introduction: Introduction, INTRODUCTION, introduction, Background, BACKGROUND, 引言, 前言, 背景, 研究背景, 背景介绍, Main

## 逻辑链

以叙事功能为单位描述段落的推进模式，名称归一化，序列积累在对应笔记中。脚本以本列表中的名称作为去重依据。归一化判断标准：遮蔽元素序列，只看这段话的叙事推进动作是什么。新建逻辑链命名禁止包含：具体疾病名、分子名、方法名、药物名、技术名。命名 2-8 字，且不得与元素辞典元素名、结果辞典手法名重名。

**疾病背景铺垫** 铺陈疾病定义、流行病学、负担或危险因素，建立研究背景。不涉及具体研究问题。

- 典型元素序列：A1/A6/A7/A8 连续铺陈
- 与"疾病问题引出"区分：背景铺垫止于陈述背景，不转向研究问题或缺口
- 与"机制铺陈"区分：背景铺垫是静态背景知识（定义/流行病学/负担），机制铺陈聚焦动态分子机制/病理生理

**疾病问题引出** 从疾病现状或临床困境切入，直接引出核心研究问题、知识缺口或研究必要性。

- 典型元素序列：A6/A7 → D1/D3
- 与"疾病背景铺垫"区分：本链有明确的"现状→问题"转向（落点在 D1/D3）
- 与"缺口承转"区分：问题引出在背景段中段引出问题；缺口承转是收尾段、直接落到研究目的（D5/D4）
- 与"文献证据梳理"区分：问题引出从疾病现状/负担（A 层）起手；文献证据梳理从文献证据（C 层）起手

**机制铺陈** 系统陈述疾病或通路的已知分子机制、病理生理过程，为后续论证铺设机制前提。

- 典型元素序列：A10/A10b 连续（可前接 A5，后接 D1）
- 与"疾病背景铺垫"区分：背景铺垫是静态背景（定义/流行病学），机制铺陈聚焦动态机制过程（A10 分子机制 / A10b 病理生理）
- 与"影响因素深入"区分：机制铺陈系统讲疾病机制本身，影响因素深入聚焦某一具体因素与疾病的关联

**影响因素深入** 聚焦某一具体影响因素，深入其生物学机制、已有证据或与疾病的关联。可在段尾以方法学缺陷或知识缺口引出转折，仍归此链。

- 典型元素序列：A8/B1/B2 → A10/A10b → （可选 D1/D2 收尾）
- 与"候选物质论证"区分：本链聚焦"因素与疾病的关联机制"，候选物质论证聚焦"该物质作为干预手段的潜力"
- 与"机制铺陈"区分：影响因素深入聚焦单一因素，机制铺陈系统铺陈疾病整体机制
- 与"文献证据梳理"区分：影响因素深入聚焦单一因素及其证据，文献证据梳理是跨多研究的主题级证据综述、不限单一因素

**文献证据梳理** 综述某主题既有研究证据的整体格局——已确立的发现、支持或反对证据、结论分歧或共识，可在段尾由此引出知识缺口。

- 典型元素序列：C1/C2 → C3/C4/C13 → （可选 D1）
- 与"疾病问题引出"区分：问题引出从疾病现状/负担（A 层）切入，本链从文献证据（C 层）切入
- 与"影响因素深入"区分：影响因素深入聚焦单一因素与疾病的关联及其证据，本链是主题层面跨多研究的证据综述、不限单一因素
- 与"历史脉络引题"区分：历史脉络引题以时间线/范式演变为主线，本链梳理的是当前证据格局（共识/分歧），非时间演进

**治疗困境展开** 展开现有治疗手段的局限、耐药、副作用或临床瓶颈，不含新疗法的论证。

- 典型元素序列：B3 → B5 → D1（治疗现状→并发症/瓶颈→缺口）
- 与"候选物质论证"区分：困境展开只陈述现有治疗的不足，不论证新候选

**候选物质论证** 论证某一候选药物、化合物或干预手段的合理性、潜力或已有证据基础。

- 典型元素序列：B1/B2 → B4/C2（属性/功能→已知疗效/支持证据）
- 与"药物开发论证"区分：候选物质论证侧重"该物质为何有潜力"，药物开发论证侧重"开发背景与可行性的完整论证"

**方法与目的** 以研究目的、策略框架或创新声明为叙事主线的段落。研究目的句可在相邻段落出现，本段仅有方法框架预告也归此链。

- 典型元素序列：D5/D6 或 E1/E2（目的/创新或策略框架主导）
- 与"研究方案陈述"区分：本链叙事重心在"目的/策略框架"，研究方案陈述重心在"操作细节逐项列举"
- 与"缺口承转"区分：本链以目的/策略为主、未必含缺口；缺口承转以缺口（D1/D2）为起点转入目的

**缺口承转** 引言收尾段，从知识缺口直接转入本研究目的或假设，完成"为什么做→做什么"的临门一脚。

- 典型元素序列：D1/D2 → D5/D4
- 与"疾病问题引出"区分：问题引出在背景段中段引出问题；缺口承转是收尾段、直接落到研究目的/假设
- 与"方法与目的"区分：缺口承转以缺口为起点（D1/D2 起手），方法与目的以目的/策略为主

**方法局限与需求** 指出现有研究方法的不足或空白，论证引入新方法的原理和价值。区别于「技术现状与缺口」（后者聚焦技术平台与工具能力）。

- 典型元素序列：D2 → E6（方法学缺陷→新方法原理/价值）
- 与"技术现状与缺口"区分：本链聚焦"方法学层面的不足与需求"，技术现状与缺口聚焦"技术平台/工具的能力与空白"

**技术现状与缺口** 描述当前技术或工具平台的发展水平或跨领域应用证据，可选衔接该技术在本疾病领域的应用空白。

- 典型元素序列：C8/C9/C15 → D1（技术现状/跨领域证据→应用空白）
- 与"方法局限与需求"区分：本链聚焦技术平台与工具能力

**研究假设与设计** 明确提出研究假设，交代研究设计的类型和框架。

- 典型元素序列：D4 → E1（假设→设计类型）
- 与"方法与目的"区分：本链明确含研究假设（D4），方法与目的以目的/策略为主、未必提出假设
- 与"缺口承转"区分：本链重心在"假设+设计框架"，缺口承转重心在"缺口→目的"的转折

**药物开发论证** 论证某一药物或治疗策略的开发背景、临床需求、已有证据与可行性。

- 典型元素序列：A7/B3 → B1/B2 → B4/C12（临床需求→物质属性→已知疗效/转化进展）
- 与"候选物质论证"区分：药物开发论证是"开发背景+需求+证据+可行性"的完整论证链，候选物质论证侧重单一物质的潜力

**合规声明** 声明研究的伦理审批、注册编号或监管合规状态。**程序性条目**：句子不承载叙事推进功能，元素辞典无对应元素，元素层可不强标；本链仅在逻辑链层记录此类声明段的存在，不参与叙事推进归类的竞争。

- 典型元素序列：（无对应内容元素，按附属成分处理）

**研究方案陈述** 段落主体由数据来源、样本量、分析流程、结局指标等操作细节的逐项列举构成。与「方法与目的」的核心区别在于叙事重心。

- 典型元素序列：E3/E4 → E5 连续（对象/数据→步骤逐项）
- 与"方法与目的"区分：本链叙事重心在操作细节逐项列举（E3/E4/E5），方法与目的重心在目的/策略框架

**历史脉络引题** 以领域发展的时间线为叙事主线，回顾从早期到当前的关键进展节点和研究范式转变，为引出当前研究方向提供历史脉络。（命名说明：原名「研究历史沿革」与元素 C7 同名，v1.3 改名避开双链串扰。）

- 典型元素序列：C7 → C10（历史沿革→当前前沿/方向）
- 与"疾病背景铺垫"区分：本链以"时间线/范式演变"为主线，背景铺垫以静态背景知识为主
- 与"文献证据梳理"区分：本链以时间线/范式演变为主线，文献证据梳理梳理当前证据格局（共识/分歧）、非时间演进

## 后续积累方式

逻辑链名称层已扩充至 16 条。新论文标注时：

1. 识别引言各段的叙事推进模式
2. 遮蔽元素序列，只看推进动作，匹配到 16 条中最近的一条
3. 将该段的元素序列追加到该逻辑链名称下，作为序列实例
4. 现有 16 条均无法覆盖时，按命名规则新建（2-8 字，禁含具体疾病/分子/方法/药物/技术名，且不与元素辞典元素名、结果辞典手法名重名）
