# 摘要写作辞典 v2.6

段落级叙事推进模式，名称归一化，序列积累在对应笔记中。

本辞典只定义逻辑链的**名称、定义与边界**。标注规则、元素序列的具体标注方法等"如何使用"的内容，由配套指令文档承接。

名称层为**受控扩充集合**。新论文优先将元素序列归入已有名称。本版已按 SCI 常见摘要结构做专家预置扩充，覆盖面较全；后续新建须满足：①现有 21 条均无法覆盖其叙事推进动作；②连续 3 篇以上独立论文出现同一新模式。

归一化判断标准：遮蔽元素序列，只看这段话的叙事推进动作是什么。命名规则：2–8 字，禁止包含具体疾病名、分子名、方法名、药物名。

背景类逻辑链中的"现状"为通用口径，泛指疾病背景（流行病学/负担/机制）或物质/干预背景（属性/已知功能/现有疗法），不限于疾病流行病学。

各逻辑链对元素的引用，统一通过"典型元素序列"中的元素 ID（A6、D1 等）表达，ID 的规范名称与定义以元素辞典 v3.4 为准；本辞典不再单列概念—元素对照表，避免近义名泄漏与映射歧义。

**典型元素序列为记录性参考，非归类依据**：逻辑链归类只看段落的叙事推进动作（遮蔽元素序列后判断）。元素序列忠实记录本文实际排列、供可视化与积累，不参与匹配。

**版本说明（v2.5 → v2.6）**：专家预置扩充，基于生物医学 SCI 常见摘要结构，由 14 条增至 21 条，覆盖临床试验、机制研究、顶刊观点型、方法学等此前未覆盖的类型。新增：一段式「顺序铺陈」「结论先行」；背景「径取问题」；目的「假设驱动」；方法「验证递进」；结果「终点汇报」「机制递进」。新增条目为专家预置（基于领域常识而非语料统计），后续靠语料验证。原 14 条名称与定义未变。速查表加「写作场景」列。

**历史**：v2.4→v2.5 同步元素辞典 F 组细化 F1–F5、新增方法筛漏；v2.3→v2.4 原 F3/F4 并入 F、H1 拆 H1/H1b、A10 增 A10b、G2 增 G2b。

## 标题名称

归一化识别摘要二级标题的各种写法，用于定位 ## Abstract 起始行。格式：归一化名称: 变体1, 变体2, ... 匹配时自动剥离序号（如 1. / 1.1 / (1) / 一、等）。

摘要: Abstract, ABSTRACT, abstract, Summary, SUMMARY, 中文摘要, 【摘要】

## 分段标题归一化

归一化识别摘要内部三级标题的各种写法，映射为中文标准段落名。格式：归一化名称: 变体1, 变体2, ... 匹配时自动剥离序号。

背景: Background, Introduction 目的: Objective, Aim, Purpose 方法: Methods, Materials and Methods, Patients and Methods, Methodology 结果: Results, Findings, Outcomes 结论: Conclusion, Conclusions, Summary, Discussion

## 逻辑链

### 一段式

**交织推进** 背景、方法、结果、结论交织在一段中推进，无明确分段标题。各功能模块穿插出现，不遵循固定顺序。

- 典型元素序列：A→E→F→H 混合穿插
- 与"缺口驱动"区分：交织推进无主导线索，各模块平权穿插；缺口驱动有明确的"缺口→填补"主线
- 与"顺序铺陈"区分：交织是模块乱序穿插；顺序铺陈是模块依自然顺序线性排列

**缺口驱动** 从知识缺口或研究空白出发，贯穿背景到结论的完整叙事。以 D1（知识缺口）为引擎句，前后铺展背景与发现。

- 典型元素序列：D1 居中驱动，前接 A/B 层铺垫，后接 E→F→H
- 与"交织推进"区分：缺口驱动有明确的"缺口→填补"主线

**顺序铺陈** 一段式摘要按"背景→目的→方法→结果→结论"的自然顺序线性推进，无交织、无单一缺口引擎。最常见的一段式形态，尤以计算、方法学论文为多。

- 典型元素序列：A/B 层 → D5 → E5/E2 → F 层 → H1/H1b（依序线性）
- 与"交织推进"区分：顺序铺陈各模块依序排列、互不穿插；交织是模块乱序穿插
- 与"缺口驱动"区分：顺序铺陈平铺直叙，无 D1 引擎句主导

**结论先行** 一段式摘要开篇即抛出核心结论或主张，再倒叙支撑性背景、方法与发现。常见于顶刊、观点性或重大发现型摘要。

- 典型元素序列：H1b/H1 起手 → A/E/F 层倒叙支撑
- 与"顺序铺陈"区分：结论先行倒置结构（先结论后支撑），顺序铺陈正序（结论收尾）
- 与"缺口驱动"区分：结论先行以结论为锚，缺口驱动以缺口为锚

### 分段式

#### 背景

**现状引题** 先铺陈领域背景——疾病现状/流行病学，或物质/干预的背景属性——再引出研究问题或知识缺口。铺垫层次较浅，通常 1–2 句背景后直接转入缺口或目的。

- 典型元素序列：A6/A7 或 B1/B2/B3/B4 → D1
- 与"现状深引"区分：现状引题铺垫浅（1–2 句），快速转入缺口；现状深引铺垫深，涉及机制、争议或矛盾证据
- 与"径取问题"区分：现状引题有背景铺垫，径取问题零背景

**现状深引** 在背景基础上进一步深入机制、争议或矛盾证据，再引出研究问题。铺垫层次较深，涉及多个知识维度。

- 典型元素序列：A6/A7 或 B 层 → A10/A10b/C4/C3 → D1
- 与"现状引题"区分：现状深引铺垫深，涉及机制（A10 分子机制 / A10b 病理生理过程）、争议（C4）或矛盾证据（C3）等多维度信息

**径取问题** 背景段零铺垫，开篇即抛出研究问题、缺口或目的，不含疾病/物质背景陈述。常见于顶刊摘要、方法学论文。

- 典型元素序列：D1 或 D5 起手，无 A/B 层铺垫
- 与"现状引题"区分：现状引题有 1–2 句背景，径取问题完全省略背景、直入问题

#### 目的

**目的陈述** 直接陈述本研究的具体目标或研究问题，不含背景铺垫。

- 典型元素序列：D5（可含 D4/D6）
- 与"假设驱动"区分：目的陈述以"做什么"（D5）为核心；假设驱动以明确科学假设（D4）为核心

**假设驱动** 以明确的科学假设为叙事核心，陈述待验证的假说而非单纯目标。常见于假设检验型研究。

- 典型元素序列：D4 起手（可接 D5）
- 与"目的陈述"区分：假设驱动含明确假设（D4，"我们假设……"），目的陈述只陈述目标（D5，"本研究旨在……"）

#### 方法

**方法铺排** 按研究步骤顺序平铺各方法模块，每句对应一个独立方法单元。不强调步骤间的编排逻辑。

- 典型元素序列：E5/E8 连续使用，句间并列
- 与"策略统领"区分：方法铺排直接进入"做了什么"，无统领句；策略统领以 E1/E2 起手，承载"为什么这样设计"的编排逻辑

**策略统领** 先交代整体研究策略或设计框架，再展开具体步骤。以"总→分"结构推进。

- 典型元素序列：E1/E2 → E5/E4/E3
- 与"方法铺排"区分：策略统领的起手句承载编排逻辑（E1/E2），方法铺排的起手句直接进入具体步骤（E5/E8）

**方法筛漏** 方法叙事呈漏斗式收敛——从大规模候选/数据出发，经逐层筛选条件收拢到少量入选对象。常见于组学、虚拟筛选、药物发现类摘要。

- 典型元素序列：E5 连续，伴随数量递减（如"25 化合物 → ADME 筛 → 7 候选"）；元素层仍为 E5 串，漏斗形状由句意承载
- 与"方法铺排"区分：方法铺排是平权的步骤平铺（流程链式，无收敛方向）；方法筛漏的步骤间有"广→窄"的筛选收敛关系
- 与"策略统领"区分：方法筛漏无"为什么这样设计"的统领句，直接以筛选动作推进
- 说明：元素辞典 E 组不区分"流程链/漏斗"（均为 E5），方法段的此类叙事差异在本逻辑链层区分

**验证递进** 方法呈"发现→验证"两阶段：先以一类方法做发现/建模，再以独立方法验证。常见于组学筛选 + 实验验证、模型 + 外部验证类研究。

- 典型元素序列：E2/E5（发现阶段）→ E5（独立验证阶段，如 in vitro / 外部队列）
- 与"方法铺排"区分：方法铺排各步平权无阶段划分；验证递进有明确的"发现段→验证段"两阶段编排
- 与"策略统领"区分：验证递进的编排逻辑特指"发现后验证"，策略统领是更一般的总分框架

#### 结果

**结果递进** 按逻辑层次逐步呈现发现，从结果推进到验证或机制解读。句间有明显的"发现→深挖"推进关系。

- 典型元素序列：F1/F2 → F5 → G2（发现→验证→解读），或 F1 → F4 → G2（数值→归纳→解读）
- 与"结果平铺"区分：递进有句间逻辑推进（"进一步发现""机制上"），平铺各句独立并列
- 与"结果筛漏"区分：递进是"浅→深"的纵向深化，筛漏是"广→窄"的横向收敛
- 与"机制递进"区分：结果递进止于结果/验证层；机制递进进一步上升到 G2b 的一般机制主张

**结果平铺** 多个独立发现并列陈述，句间无推进或递进关系。各句独立呈报，互不依赖。

- 典型元素序列：F1/F2 连续并列（各发现平权，主次/亚组等作 F1 属性）
- 与"结果递进"区分：平铺各句独立并列，无句间逻辑推进、无 F4 归纳收拢
- 与"结果筛漏"区分：平铺各发现平权、无收敛方向；筛漏的数据量逐步递减、向核心靶点收拢
- 与"终点汇报"区分：平铺各发现平权无层级；终点汇报有"主要→次要→安全性"的预设指标层级

**结果筛漏** 从广泛筛选逐步聚焦到关键发现，呈漏斗式收敛。常见于组学/生信论文。

- 典型元素序列：F1（海量，如"443 个靶点"）→ F2/F4（逐层聚焦、归类）→ F5（锁定核心后呼应验证）
- 与"结果平铺"区分：筛漏是"广→窄"的横向收敛（数据量递减），平铺是各发现平权并列、无收敛方向
- 与"结果递进"区分：筛漏是"广→窄"的横向收敛，递进是"浅→深"的纵向深化（理解层次递增）

**终点汇报** 按预设结局指标逐项汇报——主要终点、次要终点、安全性/亚组。RCT、队列、临床干预研究的典型结果结构。

- 典型元素序列：F2（主要终点对比）→ F2/F1（次要终点）→ F1（安全性/亚组）
- 与"结果平铺"区分：终点汇报有"主要→次要→安全"的预设指标层级，平铺各发现平权无层级
- 与"结果筛漏"区分：终点汇报按指标分类汇报、无数据收敛，筛漏是数据量递减的漏斗

**机制递进** 结果叙事从发现上升到机制：先报结果，再解读，最终推断出更一般的机制或新假说。常见于机制研究型摘要。

- 典型元素序列：F1/F2 → G2（解读）→ G2b（一般机制主张）
- 与"结果递进"区分：机制递进必含 G2b 的一般机制上升，结果递进止于结果/验证/普通解读层
- 与"收束"区分：机制递进发生在结果段内的推进，收束是结论段的收尾动作

#### 结论

**收束性陈述** 将主要发现凝练为结论，或归因为具体机制、整合多条证据链，以收束性陈述结尾。

- 典型元素序列：H1（结果凝练）或 H1b（核心论断）起手，可前接 G2/G2b（机制推断/递进）或并列多条 F 层发现后收束
- 起手句为事实凝练用 H1，为价值判断/立场主张用 H1b；归到单一机制 vs 整合多链的差异由元素序列承载，名称层不区分
- 与"意义展望"区分：收束落点在"是什么/为什么"（机制或结论本身），意义展望落点在"有什么用/下一步做什么"
- 与"框架结论"区分：收束不涉及理论框架的命名或定位

**意义展望** 从核心结论延伸到临床意义、公共卫生意义或未来研究方向。

- 典型元素序列：H1/H1b → H2/H5
- 与"收束"区分：意义展望落点在"有什么用"，收束落点在"是什么机制/结论"

**框架结论** 将发现嵌入已有理论框架或提出新框架、新模型。

- 典型元素序列：H1b → C5（嵌入已有框架）或 H1b → D6（提出新框架）
- 与"收束"区分：框架结论的落点在"理论定位"，涉及理论/模型的命名或引用；起手多为价值主张（H1b）而非单纯事实凝练
- 与"意义展望"区分：框架结论强调"学术定位"，意义展望强调"实践价值"

## 后续积累方式

逻辑链名称层已扩充至 21 条并冻结。新论文标注时：

1. 将摘要按段落类型（一段式/分段式）识别其叙事推进模式
2. 遮蔽元素序列，只看推进形状，匹配到 21 条中最近的一条
3. 将该论文的元素序列追加到该逻辑链名称下，作为新的序列实例
4. 若连续 3 篇以上独立论文出现同一新模式且 21 条无法覆盖，走受控新建协议
