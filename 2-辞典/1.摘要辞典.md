# 摘要写作辞典 v2.3

段落级叙事推进模式，名称归一化，序列积累在对应笔记中。

本辞典只定义逻辑链的**名称、定义与边界**。标注规则、元素序列的具体标注方法等"如何使用"的内容，由配套指令文档承接。

名称层为**封闭集合**。新论文优先将元素序列归入已有名称。新建逻辑链须同时满足：①现有 13 条均无法覆盖其叙事推进动作；②连续 3 篇以上独立论文出现同一新模式。

归一化判断标准：遮蔽元素序列，只看这段话的叙事推进动作是什么。命名规则：2–8 字，禁止包含具体疾病名、分子名、方法名、药物名。

背景类逻辑链中的"现状"为通用口径，泛指疾病背景（流行病学/负担/机制）或物质/干预背景（属性/已知功能/现有疗法），不限于疾病流行病学。

各逻辑链对元素的引用，统一通过"典型元素序列"中的元素 ID（A6、D1 等）表达，ID 的规范名称与定义以元素辞典 v3.2 为准；本辞典不再单列概念—元素对照表，避免近义名泄漏与映射歧义。

摘要: Abstract, ABSTRACT, abstract, Summary, SUMMARY, 中文摘要, 【摘要】

## 分段标题归一化

归一化识别摘要内部三级标题的各种写法，映射为中文标准段落名。格式：归一化名称: 变体1, 变体2, ... 匹配时自动剥离序号。

背景: Background, Introduction 目的: Objective, Aim, Purpose 方法: Methods, Materials and Methods, Patients and Methods, Methodology 结果: Results, Findings, Outcomes 结论: Conclusion, Conclusions, Summary, Discussion

## 逻辑链

### 一段式

**交织推进** 背景、方法、结果、结论交织在一段中推进，无明确分段标题。各功能模块穿插出现，不遵循固定顺序。

- 典型元素序列：A→E→F→H 混合穿插
- 与"缺口驱动"区分：交织推进无主导线索，各模块平权穿插；缺口驱动有明确的"缺口→填补"主线

**缺口驱动** 从知识缺口或研究空白出发，贯穿背景到结论的完整叙事。以 D1（知识缺口）为引擎句，前后铺展背景与发现。

- 典型元素序列：D1 居中驱动，前接 A/B 层铺垫，后接 E→F→H
- 与"交织推进"区分：缺口驱动有明确的"缺口→填补"主线, 现状深引

### 分段式

#### 背景

**现状引题** 先铺陈领域背景——疾病现状/流行病学，或物质/干预的背景属性——再引出研究问题或知识缺口。铺垫层次较浅，通常 1–2 句背景后直接转入缺口或目的。

- 典型元素序列：A6/A7 或 B1/B2/B3/B4 → D1
- 与"现状深引"区分：现状引题铺垫浅（1–2 句），快速转入缺口；现状深引铺垫深，涉及机制、争议或矛盾证据

**现状深引** 在背景基础上进一步深入机制、争议或矛盾证据，再引出研究问题。铺垫层次较深，涉及多个知识维度。

- 典型元素序列：A6/A7 或 B 层 → A10/C4/C3 → D1
- 与"现状引题"区分：现状深引铺垫深，涉及机制（A10）、争议（C4）或矛盾证据（C3）等多维度信息

#### 目的

**目的陈述** 直接陈述本研究的具体目标或研究问题，不含背景铺垫。

- 典型元素序列：D5（可含 D4/D6）

#### 方法

**方法铺排** 按研究步骤顺序平铺各方法模块，每句对应一个独立方法单元。不强调步骤间的编排逻辑。

- 典型元素序列：E5/E8 连续使用，句间并列
- 与"策略统领"区分：方法铺排直接进入"做了什么"，无统领句；策略统领以 E1/E2 起手，承载"为什么这样设计"的编排逻辑

**策略统领** 先交代整体研究策略或设计框架，再展开具体步骤。以"总→分"结构推进。

- 典型元素序列：E1/E2 → E5/E4/E3
- 与"方法铺排"区分：策略统领的起手句承载编排逻辑（E1/E2），方法铺排的起手句直接进入具体步骤（E5/E8）

#### 结果

**结果递进** 按逻辑层次逐步呈现发现，从主要结果推进到机制或深层解读。句间有明显的"发现→深挖"推进关系。

- 典型元素序列：F1 → F2 → G2
- 与"结果平铺"区分：递进有句间逻辑推进（"进一步发现""机制上"），平铺各句独立并列
- 与"结果筛漏"区分：递进是"浅→深"的纵向深化，筛漏是"广→窄"的横向收敛

**结果平铺** 多个独立发现并列陈述，句间无推进或递进关系。涵盖按分析层级（主要分析→敏感性分析→亚组分析）逐层呈现的情况。

- 典型元素序列：F1 → F2 → F3 并列使用
- 与"结果递进"区分：平铺各句独立并列，无句间逻辑推进。"主→敏感性→亚组"的层级递进信息由元素序列（F1→F3）承载，名称层不单列

**结果筛漏** 从广泛筛选逐步聚焦到关键发现，呈漏斗式收敛。常见于组学/生信论文。

- 典型元素序列：F1/F2 连续使用，从海量数据向核心靶点收拢
- 与"结果递进"区分：筛漏是"广→窄"的横向收敛（数据量递减），递进是"浅→深"的纵向深化（理解层次递增）

#### 结论

**收束** 将主要发现归因为具体机制，或整合多条证据链提炼为统一结论，以收束性陈述结尾。

- 典型元素序列：H1 起手，可前接 G2（机制推断）或并列多条 F 层发现后收束
- 归到单一机制 vs 整合多链的差异由元素序列承载，名称层不区分
- 与"意义展望"区分：收束落点在"是什么/为什么"（机制或结论本身），意义展望落点在"有什么用/下一步做什么"
- 与"框架结论"区分：收束不涉及理论框架的命名或定位

**意义展望** 从核心结论延伸到临床意义、公共卫生意义或未来研究方向。

- 典型元素序列：H1 → H2/H5
- 与"收束"区分：意义展望落点在"有什么用"，收束落点在"是什么机制/结论"

**框架结论** 将发现嵌入已有理论框架或提出新框架、新模型。

- 典型元素序列：H1 → C5（嵌入已有框架）或 H1 → D6（提出新框架）
- 与"收束"区分：框架结论的落点在"理论定位"，涉及理论/模型的命名或引用
- 与"意义展望"区分：框架结论强调"学术定位"，意义展望强调"实践价值"

## 后续积累方式

逻辑链名称层已冻结。新论文标注时：

1. 将摘要按段落类型（一段式/分段式）识别其叙事推进模式
2. 遮蔽元素序列，只看推进形状，匹配到 13 条中最近的一条
3. 将该论文的元素序列追加到该逻辑链名称下，作为新的序列实例
4. 若连续 3 篇以上独立论文出现同一新模式且 13 条无法覆盖，走受控新建协议
