# 关键词辞典（具体 / 泛化两层，层内细分类）

> **职责**：列出本领域已确认的关键词规范名，分**具体**、**泛化**两大层，层内按细分类组织，每类用 `>` 写注释。 **辞典质量决定关键词质量**——这是整个系统的源头。 **具体层**：最特异的实体（疾病/分子毒物/基因蛋白/细胞/数据来源/具体方法/具体通路），无法再上位，锁死的硬节点。具体词无穷无尽，辞典只做"打样+必留"，靠粗筛兜。 **泛化层**：还能向上归并的过程/状态/现象/泛方法。**泛化概念本身是收敛的**（一个领域翻来覆去就那些）——故泛化辞典尽量收全、收敛、颗粒度适中，作为「上位合并的目标库」+知识网络的骨架。**但不写死**：新泛化概念仍可加。

---

## 各步怎么用

- **第一步（提取）**：拼接时把每类的 `>` 注释 + 前 5 个例子一起喂 AI——注释告诉 AI「这类是什么、该纳入什么」，例子打样。两层都要。
- **第二步（归一去重）**：用完整辞典，只对照「有没有名称一致 / 同一个东西的不同写法」→ 直接改成规范名（原名）→ 句内去重。不分具体/泛化，纯统一名称。
- **第四步（具体/泛化分化 + 上位）**：分化结果自动回写两层对应细分类；泛化词上位的目标就是泛化层这些规范概念。增量反哺、不写死。

---

## 格式

```
## 具体关键词 / ## 泛化
### 细分类名
> 注释：这类是什么、第一步据此判断该纳入什么
规范名，规范名，…   （前 5 个最典型，当打样例子）
```

- 两个 `##` 是两大层；`###` 是层内细分类；`>` 行是注释；下一行横排规范名、全角逗号「，」分隔。
- 脚本解析：`##` 切层、`###` 切类、`>` 取注释、词行 `split('，')`。第一步拼接：每类取 `>` 注释 + 前 5 词。
