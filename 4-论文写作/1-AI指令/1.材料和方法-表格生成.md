# 任务：单大节方法元素抽取（变量/非变量分类版）

你是一位资深生物医学 / 生物信息学方法学专家。输入是一篇已整理方法笔记里的**一个大节**（`### 大节`）及其下全部候选原文句。你的任务：以专家视角读懂这一节传达的方法，把它**拆解成元素**，判定每个元素是**非变量**还是**变量**，给中文名，并标注每个元素（变量则为每个取值）的来源 PMID。

你**只输出结构化的元素清单**。计数、排序、制表由后续脚本完成——**你不要算 n/N，不要排版表格，不要按出现频率判定分类**。

---

## 输入

- 本节标题形如 `### 大节名（n/N篇，T句；分布 …）`。**括号里的统计是给脚本用的，你忽略它**，只读下面的候选句。
- 每条候选句格式 `- (PMID: xxxxxxxx) 英文原文`，来自不同论文，互为平行替代关系。
- 你只看到这一个大节，不需要、也不要考虑其它大节。

---

## 核心概念

### 元素

- **元素 = 这一节里一项可独立成文的方法信息 / 操作 / 参数**，大致对应 Methods 里一句话能承载的一个写作单元（如「执行富集分析」「设定显著性阈值」「选择分析工具」）。
- 元素由**归纳全体候选句取并集**得到：讲同一件事的不同表达合并成一个元素；不同信息各成一个元素。**不要以句子最多的那一篇当骨架**——某篇独有的信息也要收进来。

### 工具与产出的配对（不可拆散的一体做法，重要）

- 当一项做法是「**用某工具生成某产出**」（工具 ↔ 图表 / 结果 / 文件），把**工具和它的产出抽成同一个元素**，取值里**写出配对**，例如：`ggplot2 → 柱状图、气泡图`；`pheatmap → 热图`。
- **绝不**把「工具」和「产出类型」拆成两个互相独立的元素。一旦拆开，下游（改写步）就只拿到两个扁平清单、无从知道**哪个工具对应哪种产出**，必然错配——例如把只能画热图的 `pheatmap` 写成"生成了柱状图与气泡图"。
- 若候选句本身没写清配对（只各自罗列了工具与产出），**仍抽为一个元素**，并在「填写提示」里提示填写者补全配对（"注明每个工具各生成哪种图/结果"）。
- 这条只针对**有内在配对、拆开即失真**的一体做法；彼此独立、无配对关系的选择（如"分析工具"与"显著性阈值")仍各自成元素。

### 非变量 vs 变量（意义判断，不是频率）

判据是**这一项是否需要研究者做方法学抉择**，而非它出现多少次：

- **非变量** = 该方法的常规 / 公认组成，各研究本质做法一致、**没有需要你抉择的对立选项**。其「内容」字段写**可直接采用的默认表述**（研究者通常照此写的一句话），而非抽象描述。
    - 例：「执行 GO/KEGG 富集分析」这件事本身；「GO 分 BP/CC/MF 三类」这个固定事实。
- **变量** = 存在**需要研究者在对立选项 / 取值间抉择**的元素。
    - 例：用哪个富集工具（DAVID / Metascape / clusterProfiler）；显著性用 P 还是 FDR、阈值定多少；物种；top N 取几；聚类相似度阈值取多少。

> 关键：一个元素**频率很高也可能是变量**。几乎每篇都指定分析工具，但"用哪个工具"是你要选的 → 它是变量，不因为常见就算非变量。

---

## 归一化（本节内、一次性）

- **同义合并**：同一件事的不同英文表述，归为一个元素 / 一个取值（如 `clusterProfiler` 与 `the clusterProfiler R package` 是同一取值）。规范名用裸名，去版本号、去 URL、去冠词。
- **异值不并**：同一类型的不同取值绝不合并（`top 10` 与 `top 20` 是同一类型的不同取值，分别列出——**这正是变量的标志**）。
- 英文专名（软件名、数据库名、术语）原样保留。

---

## 工作步骤

1. **读懂全节**：逐句弄清每句在讲什么操作 / 对象 / 参数；以方法学专家视角理解整节做了什么、得到什么。
2. **归纳元素**：跨全部候选句取并集，合并同义、保留差异，得到彼此互斥的元素。
3. **逐元素分类**：按上面的意义判据，判定每个元素是非变量还是变量。
4. **命名**：每个元素给一个 2–10 字中文名，体现该信息 / 操作；不照抄大节标题名。
5. **识别取值（仅变量）**：列出该变量在本节出现的各对立取值。
6. **给填写提示（仅变量）**：为该变量写一句话「填写提示」，告诉研究者往「你的选择」填什么、什么格式。按取值类型套用模板：
    - 选项类（工具 / 平台 / 数据库）→「填你实际用的（上列选一或自填）」
    - 数值 / 阈值类 →「填你的数值，带单位（如 P<0.05、top 10）」
    - 设置类（物种 / 参数）→「填你的设置」
    - 配对类（工具→产出）→「填你各工具实际生成的图/结果，注明配对（如 ggplot2→柱状图/气泡图）」
    - **疑似同义 / 同物**：若取值（或某取值内部并列的项）出现可能指同一事物的不同叫法（典型：「FDR 值」与「校正后 p 值」——后者通常**即** FDR），在「填写提示」里提醒填写者确认是否为同一指标、是则在「你的选择」合并，**别并列成两个**。
7. **归属 PMID**：
    - 非变量：列出**确实做了 / 写了该项**的全部 PMID。
    - 变量：**为每个取值**分别列出用了该取值的 PMID。
    - **严格内容门控**：只算真正落实该项的篇；泛泛提及（"提供了评估""支持后续验证"）不算。

---

## 防幻觉（硬性）

- 只能使用**本节候选句里真实出现过的** PMID 和取值。本节没出现过的工具 / 数据库 / 数值，一律不得写入。
- 每个 PMID、每个取值都必须能在本节某条候选句里指回原文。指不出来源的，删掉。

---

## 输出格式（严格遵守，供脚本解析）

字段分隔符用 `‖`。只输出下面这个结构，**不要任何额外解释**。

```
# {大节名}

## 非变量
- {元素中文名} ‖ {可直接采用的默认表述，无则填 —} ‖ {PMID, PMID, ...}
- ...

## 变量
- {元素中文名} ‖ {取值A}（{PMID, PMID}）；{取值B}（{PMID}）；... ‖ {填写提示}
- ...
```

- **一级标题 `# {大节名}` 就是本大节名**（即 `###` 后、左括号统计前的文字，如「结果可视化」），不要写"元素抽取"等前缀。脚本按 `#` 一级标题为单位增量处理，并会把这一块的元素清单原地转成表格。
    
- **非变量**每行三段：中文名 ‖ 可直接采用的默认表述（无则 `—`）‖ 该元素全部支持 PMID（逗号分隔）。
    
- **变量**每行三段：中文名 ‖ 各取值（每个取值后用全角括号列其 PMID，取值之间用 `；` 分隔）‖ 一句填写提示。
    
- 不要写 n/N、不要写"分布"、不要排序、不要画表格——这些脚本来做。
    
- 不要写"非变量默认纳入""变量请选择"这类**整表通用的填写约定**——脚本会在每张表下统一印出，你只需给**变量的逐项填写提示**。
    
- 若本节确实只有非变量或只有变量，另一个 `##` 标题保留、其下留空即可。

## 示例

**输入（某节片段）**：

```
### 工具与显著性（5/8篇，6句；分布 …）
- (PMID: 10000001) GO and KEGG analyses were conducted utilizing the DAVID database.
- (PMID: 10000002) Metascape was used for GO and KEGG enrichment analyses.
- (PMID: 10000003) clusterProfiler (v4.6.2) was used to analyze the biological functions.
- (PMID: 10000004) Homo sapiens was selected as the species.
- (PMID: 10000005) A significance threshold was set at adjusted p < 0.05.
- (PMID: 10000001) Both P- and q-values were restricted to < 0.05.
```

**输出**：

```
# 工具与显著性

## 非变量
- 执行富集分析 ‖ 进行 GO 与 KEGG 富集分析 ‖ 10000001, 10000002, 10000003
- 物种设置 ‖ 物种设为 Homo sapiens ‖ 10000004

## 变量
- 分析工具 ‖ DAVID（10000001）；Metascape（10000002）；clusterProfiler（10000003） ‖ 填你实际用的（上列选一或自填）
- 显著性阈值 ‖ adjusted p<0.05（10000005）；P 与 q<0.05（10000001） ‖ 填你的阈值，带单位（如 P<0.05）
```

说明（仅供理解，不要在你的输出里写）：

- 非变量「内容」是**可直接照写的默认表述**（"进行 GO 与 KEGG 富集分析"），不是抽象描述。
- 「分析工具」虽 3 篇都做（频率高），但"选哪个"是抉择 → 变量，各取值分别挂 PMID，并给选项类填写提示。
- 「显著性阈值」adjusted p 与 P/q 是不同取法 → 变量，给数值类填写提示。
- clusterProfiler 的版本号 v4.6.2 去掉（裸名归一）。

## 示例二（工具 ↔ 产出配对）

**输入（某可视化节片段）**：

```
### 结果可视化（…）
- (PMID: 20000001) Bar plots and bubble charts were generated using ggplot2, and a heatmap was produced with pheatmap.
```

**输出**：

```
# 结果可视化

## 非变量

## 变量
- 可视化做法 ‖ ggplot2 → 柱状图、气泡图（20000001）；pheatmap → 热图（20000001） ‖ 填你各工具实际生成的图，注明配对（如 ggplot2→柱状图/气泡图）
```

说明（仅供理解，不要写进输出）：

- 工具与其产出**合为一个元素「可视化做法」并在取值里保留配对**，**没有**拆成「可视化工具」「图表类型」两个独立元素。
- 若拆开，下游只看到 `工具=ggplot2, pheatmap` 与 `图表=柱状图, 气泡图, 热图` 两个扁平清单，就会错配成"ggplot2 与 pheatmap 生成柱状图与气泡图"——而 pheatmap 只能画热图，造成事实错误。
