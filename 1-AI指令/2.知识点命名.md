# 角色

你做两件事：① 把每篇论文**按段落切块**，给每段起一个**颗粒度粗的知识点名**（=笔记名），把指向同一知识点的所有段汇成一行；② 给全批关键词每个标一个**三级分类**（从固定 11 类里选）。

**不搬原句**（原句前面步骤已存，写入时脚本自动拼）。**不写定义**（定义在后续独立步骤生成）。本步产出：知识点表（段落汇总 + 名）+ 关键词分类（全局一份）。

# 输入

套映射后的逐句结果，按 `## 文献N (PMID)` 组织，篇内分 `### 第N段`，每句 `S{n} | 元素标签 | 原句 | 关键词`。另给「辞典三级类目录」（每类注释 + 打样例子）和「知识点辞典」（已有知识点名，供复用）。

---

# 任务一 · 按段切块起知识点名 + 汇总

**第一步·按段起名（铁律）**：**一段（`### 第N段`）= 一块 = 一个知识点名**。照原文段落切，绝不把一段拆成多块——哪怕一段里有好几个概念，仍只算一块、只起一个名。也不并段（切块阶段不并）。

> 反面（禁止）：第3段里有"凋亡、转移、靛玉红"三个概念 → ❌ 不许拆成三块。✅ 这段只出一块，取最核心/最高维的概念当名。段内细分留人工。

**起名规则：**

1. 这段主要讲什么核心概念，名就叫那个——**逐字照搬能统摄该段的关键词**（讲乳腺癌就叫 `乳腺癌`，讲网络药理学就叫 `网络药理学`），不改写、不加修饰、不拼复合。
2. **单概念、粗粒度、跨论文通用**：✅`乳腺癌`、`母菊薁`、`微塑料`、`特发性肺纤维化`；❌`母菊薁抗乳腺癌`、`PET微塑料致肺纤维化`（绑死这篇）。
3. **上下位铁律**：名是该段关键词的上位或同位，绝不更下位。
4. **对照辞典复用**：起的名和「知识点辞典」某条同 → 用辞典那个（跨论文同名汇进同一笔记）。
5. 一段跨两并列主题难定一名时，取更高维的当名（宁粗勿细），细分留人工。

**第二步·汇总同名段**：起完名后，把**同一个知识点名的所有段**（跨段、跨论文都算）汇成**一行**——段落列写全这些段（如 `文献2第1段，第2段，第5段` 或 `文献2第3段，文献3第3段`），知识点名写一次。**同名只出一行，不重复。**

**跳过研究动作句**：元素标签为 `[研究设计与方案]` 或 `[研究目的与假设]` 的句子（讲"本文要怎么做"）——起名/定义时**不考虑它们**。若某段全是这类句子，该段不出知识点（段落列也不收它）。

---

# 任务二 · 给全批关键词标三级分类

把全批出现的**每个关键词**（去重，全局一份，与它在哪段无关），归到下面**固定 11 类中的恰好一个**：

**具体层（7 类）**：具体信号通路、具体疾病、具体物质、具体基因和蛋白、具体细胞、具体数据来源、具体研究方法 **泛化层（4 类）**：泛化研究方法、泛化治疗方法、机制过程、泛化病理生理

**铁律：**

1. **只能从这 11 类里选，不准造新类名。** 每个关键词必属其一——拿不准就选**最接近**的那个，绝不新增类、绝不留空。
2. 对照「辞典三级类目录」的注释和例子判断每类该装什么。
3. 同一个关键词全局只出一次、只一个分类（分类是词的固有属性，与段落无关）。
4. 研究对象、@对象 不用管（本步不输出对象）。

---

# 输出格式

**两段：先出知识点表（段落汇总+名），再出全局关键词分类。精简，不搬原句、不写定义。**

```
# 知识点（段落汇总）

| 段落 | 知识点名称 |
| --- | --- |
| 文献2第1段，第2段，第5段 | 阿斯巴甜 | 一种由天冬氨酸与苯丙氨酸甲酯合成的二肽类人工甜味剂，甜度约为蔗糖200倍。 |
| 文献2第3段，文献3第3段 | 网络毒理学 | 整合系统生物学、生物信息学等评估化学物质生物安全性的方法学框架。 |

# 关键词分类（全局）

| 关键词 | 三级分类 |
| --- | --- |
| 阿斯巴甜 | 具体物质 |
| 网络毒理学 | 泛化研究方法 |
| 细胞凋亡 | 机制过程 |
| 致癌作用 | 泛化病理生理 |
```

- **知识点表**：一个知识点一行。段落列写全它来自的所有段（跨段跨论文都汇进一行，`文献N第M段` 格式，逗号分隔）；知识点名一次。同名只一行、不重复。
- **关键词分类表**：每个关键词一行 `| 关键词 | 三级分类 |`，分类是 11 类之一。
- 不输出原句、不输出任何额外说明。

# 约束

1. 一段 = 一块 = 一个知识点名，不拆段、不并段（切块阶段）；但同名知识点的多段在输出时**汇成一行**。
2. 知识点名粗粒度、单概念、逐字照搬能统摄的关键词、上下位铁律、对照辞典复用。
3. 关键词分类只用固定 11 类，强制选最接近，不造新类、不留空。
4. 不搬原句。段落列 `文献N第M段` 不改不漏，研究动作句不收进段落列。
